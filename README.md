# 길빛 · 도보 길찾기

한지색·창호·처마 모티프를 적용한 React + TypeScript + Vite 모바일 웹입니다. 기존 디자인 시안과 TMAP 검색·도보 경로 연결 모드를 구분합니다.

## 실행

```sh
npm ci
npm run dev
```

Node.js 22 또는 24와 Chrome을 사용합니다. 터미널에 표시되는 로컬 주소를 엽니다. 배포용 파일은 `npm run build`로 `dist`에 생성됩니다. `npm run preview`는 정적 화면 확인용이며 서버 API를 실행하지 않습니다.

## 둘러보기

홈 → 검색 결과 → 장소 선택 → 경로 확인 → 지도 안내 → 카메라 안내.
기본 주소는 검토용 테두리·설명판 없이 앱 화면만 표시합니다. `?preview=1`에서 디자인 검토 도구를 열면 방향 재확인, 도착, 어두운 카메라 배경도 확인할 수 있습니다. 검토 모드의 넓은 화면에서는 오른쪽 화면 목록을 이용할 수 있습니다.

시안 모드의 지도·주소·이동 정보는 가상 데이터입니다. 이 모드는 위치 권한을 요청하지 않으며, 카메라는 **실제 카메라 켜기**를 누를 때만 권한을 요청합니다. 만족도는 메모리에만 유지합니다.

홈의 **실제 장소로 길찾기** 또는 `/?mode=live`에서 실제 검색·도보 경로 연결 화면을 엽니다. 발급받은 TMAP 키를 설정해야 사용할 수 있으며, 키가 없으면 준비 문구를 표시합니다. 실제 모드는 버튼을 눌렀을 때 현재 위치를 확인하고 도보 경로를 요청합니다. 실제 검색 모드에 카메라 결합·이동 추적·자동 회전 안내·도착 판정·PWA 설치는 다음 개발 범위입니다. 카메라 시안에서는 실제 영상 미리보기를 별도로 사용할 수 있습니다.

키 발급과 환경 설정은 [설정 안내](docs/navigation-setup.md)를 참고하세요. 실제 키를 커밋하지 않습니다.

거리 사진은 사용자가 제공한 Stitch 내보내기 HTML에 연결된 자산을 참고용으로 보관합니다. 실제 서비스 공개 전 이미지 사용 조건을 확인하거나 자체 사진으로 교체해야 합니다. 한옥·지도·아이콘은 프로젝트 안의 SVG입니다. 현재 명조와 고딕은 Noto Serif KR·Noto Sans KR을 로컬로 사용합니다. 폰트 공개 배포 시 해당 라이선스 고지를 함께 제공해야 합니다.

사용자 제공 디자인 가이드 원본은 `DESIGN.reference.md`, 충돌하는 색상 설정의 해석과 시안 적용 기준은 `DESIGN.md`에 정리했습니다.

## 주요 파일

- `src/main.tsx`: 7개 화면과 클릭 흐름
- `src/ui.tsx`: 로고·한옥·아이콘·지도 공통 요소
- `src/style.css`: 디자인 토큰과 모바일 반응형 스타일
- `src/navigation/`: 실제 검색·위치·경로·TMAP 지도 연결
- `server/navigation.ts`: 입력 검사·제공사 요청·응답 정규화
- `api/navigation.ts`: Vercel Functions 진입점
- `vite.config.ts`: 동일 API를 제공하는 로컬 개발 서버

## 최근 이용 기록
