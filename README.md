# 길빛 · 클릭 가능한 디자인 시안

한지색·창호·처마 모티프를 적용한 React + TypeScript + Vite 모바일 웹 시안입니다.

## 실행

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. 배포용 파일은 `npm run build`로 `dist`에 생성됩니다. 빌드 확인은 `npm run preview`를 사용합니다.

## 둘러보기

홈 → 검색 결과 → 장소 선택 → 경로 확인 → 지도 안내 → 카메라 안내.
상단 ‘디자인 시안’ 또는 ‘안내 시안’ 메뉴에서 방향 재확인, 도착, 어두운 카메라 배경도 확인할 수 있습니다. 넓은 화면에서는 오른쪽 화면 목록을 이용할 수 있습니다.

지도·주소·이동 정보는 가상 데이터입니다. 위치·카메라 권한을 요청하거나 API에 연결하지 않습니다. 만족도는 메모리에만 유지하며 서버에 저장하지 않습니다. PWA 설치·오프라인·실제 내비게이션 기능은 아직 포함하지 않습니다.

거리 사진은 사용자가 제공한 Stitch 내보내기 HTML에 연결된 자산을 참고용으로 보관합니다. 실제 서비스 공개 전 이미지 사용 조건을 확인하거나 자체 사진으로 교체해야 합니다. 한옥·지도·아이콘은 프로젝트 안의 SVG입니다. 현재 명조와 고딕은 Noto Serif KR·Noto Sans KR을 로컬로 사용합니다. 폰트 공개 배포 시 해당 라이선스 고지를 함께 제공해야 합니다.

사용자 제공 디자인 가이드 원본은 `DESIGN.reference.md`, 충돌하는 색상 설정의 해석과 시안 적용 기준은 `DESIGN.md`에 정리했습니다.

## 주요 파일

- `src/main.tsx`: 7개 화면과 클릭 흐름
- `src/ui.tsx`: 로고·한옥·아이콘·지도 공통 요소
- `src/style.css`: 디자인 토큰과 모바일 반응형 스타일

외부 서비스 키나 환경 변수는 필요하지 않습니다.
