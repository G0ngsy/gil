# 길빛 앱 설치

## 휴대폰에서

1. 갤럭시 Chrome에서 https://gilbit.vercel.app 을 연다. 인앱 브라우저/시크릿 모드에서는 일반 Chrome 창으로 다시 연다.
2. 홈 아래 ‘길빛 설치’가 나타나면 누르고 브라우저 설치창에서 승인한다. 자동으로 설치하지 않는다.
3. 버튼이 ‘설치 방법 보기’이면 안내를 펼치거나 Chrome의 ⋮ → 홈 화면에 추가/앱 설치를 사용한다. iPhone은 Safari 공유 메뉴 → 홈 화면에 추가를 사용한다. 메뉴 표현·노출 시점은 브라우저마다 다르다.
4. 홈 화면의 길빛 아이콘으로 열면 주소창 없는 앱 창으로 실행되도록 설정했다. 설치 완료 이벤트를 받거나 앱 창으로 실행 중이면 설치 안내를 숨긴다.

설치는 오프라인 길찾기를 뜻하지 않는다. 지도·검색·경로에는 인터넷이 필요하다. 카메라/GPS 권한 및 백그라운드 중지 정책도 기존과 같다. 오프라인에서 새로 열거나 새로고침하면 인터넷 연결 안내를 표시한다. 이동 중 연결이 끊겼다고 기존 화면을 즉시 강제로 바꾸거나 모든 센서를 중지하는 기능은 이번 범위가 아니다.

## 구현/갱신

manifest.webmanifest의 id/start_url/scope는 루트, display는 standalone, 이름은 길빛이다. 원래 SVG 아이콘을192/512 PNG 및 안전 여백을 둔 maskable512로 렌더링했다. iOS 홈 아이콘도 연결한다.

서비스워커는 정적 offline.html만 캐시한다. API·검색·GPS·TMAP 타일·JS/HTML 앱 번들은 보관하지 않는다. 네트워크 탐색 실패 때만 오프라인 안내를 반환한다. SW/manifest는 no-cache 헤더로 갱신을 확인한다. 강제 skipWaiting을 사용하지 않아 진행 중 앱을 즉시 교체하지 않으며, 새 서비스워커가 대기하면 기존 탭을 닫고 다시 연다. 오프라인 안내를 변경할 때 SW 캐시 버전도 갱신한다.

개발 서버에서는 서비스워커를 등록하지 않는다. `npm run build` 후 `node scripts/verify-pwa.mjs`로 production 빌드의 설치 판정/오프라인/복귀를 검사한다. 공개 배포 검증은 `node scripts/verify-pwa.mjs --url=https://gilbit.vercel.app/`를 사용한다. 별도 자동화 프로필만 사용하며 실제 사용자 프로필/설치 앱은 변경하지 않는다. API는 모의 설정 응답으로 격리하며 실제 TMAP 기능을 검사하는 명령은 아니다.

[상세 문제/검증](issues/2026-11-13-installable-pwa.md). 실제 Android 설치창 승인·홈 화면 아이콘·standalone 실행은 휴대폰에서 최종 확인해야 한다.
