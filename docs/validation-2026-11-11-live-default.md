# 실제 검색 기본 진입 검증

## 변경과 기준

기준 8f9f4f9. 기본 진입을 실제 검색으로 바꾸고 고정 예시와 모의 센서를 preview=1의 별도 모듈로 분리했다. mock fixture를 삭제하지 않고 검토 경로를 명시해 자동화 범위를 유지한다.

## 로컬 검증

- 단위 102개 통과. 기본/과거 mode·screen URL의 실제 검색 처리와 검토 플래그 라우팅 포함.
- 타입 검사·Vite 빌드 통과. 실제 앱 기본 번들과 DemoApp/SimulationNavigation 별도 번들 생성 확인.
- 고정 예시 주소·예시 현재 위치·모의 검증 제목은 검토 모듈에만 포함됨을 빌드 산출물 검색으로 확인했다.
- 최종 전체 브라우저 83개 통과. 기본 URL 4종의 실제 검색·예시 데이터/복귀 버튼 부재·검토 모듈 요청 없음 확인.
- 검토용 GPS/방위/카메라·기록 회귀는 preview=1 주소로 수행. 실제 API는 이 자동화에서 모의했으며 실기기 검증이 아니다.
- 첫 분리에서 React.lazy/Suspense와 정지된 테스트 시계가 경합해 모의 화면 렌더링 대기 테스트 1개가 시간 초과됐다. 해당 실행을 중단하고 동적 import 완료 후 루트 렌더링으로 수정했다. 수정 후 전체 재실행이 83개 통과한 결과다.
- React 검토: 동적 import는 검토 조건에서만 수행, 기본 앱의 effect/권한 수명주기 유지, 기존 실제/예시 저장 키 분리 유지, 실패 시 가상 결과로 대체하지 않음 확인.

## 남은 범위

지도 키는 보류 상태, 실제 경로 카메라·방위 결합 및 실외 정확도는 미확인이다. 검토 플래그는 접근권한 기능이 아니다. 사용자의 저장 기록은 삭제하지 않았다. 공개 화면의 예시 노출 제거와 자동 테스트 fixture 보존을 구분한다.

배포 결과는 확인 후 추가한다. 작업은 사용자 지시에 따른 AI 지원 리팩터링·자동 검증·문서화이며 사용자 성과 수치는 측정하지 않았다.
