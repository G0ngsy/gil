# 길빛 실제 화면 전환 목록

최종 확인: 2026-11-27. 실제 모드 기준이며 시안/비교용 스플래시는 별도다. 전환은 본문에 적용하고 상단 헤더는 제목을 갱신한다.

| 화면/이동 | 전환 | 시간·동작 |
|---|---|---|
| 첫 실행→홈 | 문 열림→중앙 로고→홈 줌인/페이드 | 전체3초, 문 열림1.1초/마지막 홈 전환0.7초 |
| 홈→내 위치 확인 | 오른쪽에서 들어오는 푸시 | 0.3초, 위치 카드를 누를 때 GPS 조회 |
| 내 위치 확인→홈 | 역방향 푸시 | 0.3초, 뒤로가기 또는 이 위치에서 길찾기. 길찾기는 홈 검색창에 초점 |
| 내 위치 확인→사진으로 주변 확인 | 오른쪽에서 들어오는 푸시 | 0.3초 |
| 사진→내 위치 확인 | 역방향 푸시 | 0.3초, 확인 완료 시 선택 장소 핀 추가. 뒤로가기는 변경 없이 복귀 |
| 사진 입력/미리보기/인식/검색어/후보/선택 결과 | 같은 사진 화면의 내용 교체 | 별도 푸시 없음, 단계 제목으로 초점 이동 |
| 홈/기록→장소 검색 결과 | 즉시 화면 교체 | 결과 카드0.32초 페이드업, 항목 지연35ms/최대210ms |
| 검색 결과↔경로 확인 | 선택 카드 확장/복귀 | 공유 카드 전환0.36초 |
| 경로 확인에서 도보 경로 계산 | 같은 화면 내용 갱신 | 거리/시간/시작 버튼 표시, 별도 화면 이동 없음 |
| 경로 확인→지도 길 안내 | 즉시 화면 교체 | GPS 세션 시작, 푸시 없음 |
| 지도→카메라 안내 | 지도 위 전체 화면 레이어 | 별도 푸시 없음, 권한/준비는 레이어 안에서 처리 |
| 카메라→지도 | 전체 화면 레이어 닫기 | GPS/지도 세션 유지, 별도 푸시 없음 |
| 지도 안내 X→홈 / 홈에서 안내로 복귀 | 즉시 화면 교체 | 안내 종료와 구분, 기존 세션 유지 |
| 홈↔이용 기록 | 양방향 푸시 | 각0.3초 |
| 홈↔개인정보·이용 안내 | 즉시 화면 교체 | 안내의 기록 관리→이용 기록도 즉시 교체 |
| 홈↔방향 센서 진단 | 즉시 화면 교체 | 센서 시작은 별도 사용자 동작 |
| 안내 정보/전체 경로 상세 접기·펼치기 | 같은 화면 내용 열기/닫기 | 페이지 푸시 없음, 높이/스크롤 갱신 |
| 안내 종료/새 안내 확인 | 중앙 확인창을 화면 위에 표시 | 페이지 푸시 없음, 취소/뒤로가기는 확인창만 닫음 |
| 도착 안내 | 지도/카메라 안의 안내 상태 변경 | 별도 도착 화면 푸시 없음 |
| 안내 종료→완료 / 완료→홈 | 즉시 화면 교체 | 별도 푸시 없음 |

## 공통 예외와 데이터 경계

- 빠른 연속 이동은 이전 전환을 정리하고 마지막 화면/방문 기록을 유지한다.
- 동작 줄이기 설정은 푸시·카드·페이드업·인트로 움직임을 생략한다.
- View Transition 미지원은0.28초 작은 이동/페이드로 대체한다. 지원 환경의 전체 폭 푸시와 구분한다.
- 사진 결과는 GPS·출발지·안내 목적지를 바꾸지 않는다. GPS 실패 시 사진 핀만 표시하고 시작은 GPS 재확인 뒤 가능하다.
