# 길 안내 바텀 시트 접기/펼치기 (2026-11-25)

## 문제
사용자 기기 화면에서 남은 거리·목적지·출입구 차이·122단계 상세·카메라 버튼이 지도 아래에 모두 노출돼 지도를 볼 수 있는 영역이 작았다.

## 원인
안내 중에도 지도 높이가 고정 범위였고 하단 안내가 일반 문서 흐름으로 이어졌다. 정보 표시 여부를 바꿔도 실제 지도 컨테이너 크기와 SDK 내부 좌표 크기를 함께 갱신하는 처리가 없었다.

## 해결방법
- 실제 안내 중 하단을 기본 접힘 바텀 시트로 구성했다. 손잡이 버튼을 누르면 접기/펼치기를 전환한다.
- 접힌 상태는 남은 거리·안내 종료를 유지하고 지도는 남은 높이를 모두 사용한다. GPS 재시작·재탐색·안내 마치기 등 현재 상태에 필요한 동작도 숨기지 않는다.
- 펼치면 목적지·출입구 차이 안내·전체 경로 상세·카메라 안내·안전 문구를 볼 수 있다. 긴 상세만 스크롤하며 접기/거리 요약은 유지한다.
- 펼친 시트는 화면의70%를 상한으로 하고 큰 글씨/상태 문구의 상단 안내 높이도 측정해 겹치지 않도록 공간을 확보한다. 지도 실패 시 기존 본문 스크롤 방식으로 안내를 제공한다.
- 지도 크기를 ResizeObserver로 관찰하고 공식 SDK resize()로 타일/터치 좌표 크기를 갱신한다. 지도를 다시 생성하거나 GPS/경로를 재시작하지 않는다.
- 상세는 hidden으로 접되 카메라 컴포넌트는 유지한다. 기존 영상·뒤로가기·GPS 수명 관리를 보존한다. 토글에 aria-expanded/aria-controls를 제공하고 키보드 Enter/클릭을 지원한다.
- 실제 안내 테스트와 시연 스크립트는 상세 접근 전 펼치기 동작을 하도록 맞췄다. 경로 확인 단계(안내 시작 전)는 정보를 그대로 보여준다.
