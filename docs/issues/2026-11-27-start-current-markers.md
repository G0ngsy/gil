# 출발 핀과 현재 위치 점 분리

## 문제
길 안내를 시작해 GPS를 받으면 출발 마커가 없어지고 현재 위치도 핀으로 표시되어 고정된 출발과 이동 중 위치를 구분하기 어려웠다.

## 원인
WalkingMap은 안내 중 markerPosition이 있으면 출발 마커를 생략했고 현재 위치에 회전하는 핀 도형을 사용했다.

## 해결방법
고정 start 좌표의 회색 출발 핀을 계속 표시하고 좌표 기준을 핀 끝에 맞췄다. 현재 위치는 흰 테두리 파란 원형 점으로 바꾸고 핀보다 높은 레이어에 놓았다. 채택된 GPS 이동 방향이 있을 때만 작은 방향 부채꼴을 표시한다. 이는 휴대폰 방위가 아니다. 오래된/대략적인 위치의 회색 표시·오차 원·레이블은 유지한다. 도착은 기존 초록 핀, 범례에는 출발/현재 위치를 별도로 표시한다. GPS 처리나 경로 진행 정책은 변경하지 않았다.
