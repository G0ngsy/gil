# 진행 중인 안내 복원 (2026-11-18)

## 문제
새로고침·브라우저 재실행 시 안내 세션이 사라졌다. 최근 목적지 기록만으로는 이어갈 경로를 구분할 수 없었다.

## 원인
실제 안내 세션이 React 메모리에만 있었다. 이전 GPS 진행값을 그대로 복원하면 현재 위치와 맞지 않는 안내·도착 상태를 보여줄 수 있다. 안내 저장 도입으로 기존 README의 ‘경로를 저장하지 않는다’ 설명도 수정이 필요했다.

## 해결방법
- 실제 안내만 별도 버전 키 gilbit.guidance.v1.live에 목적지·경로 좌표·저장 시각을 보관한다. 실시간 GPS 관측·이동 이력·진행값·카메라 상태는 보관하지 않는다.
- 홈의 ‘이전 안내를 이어갈까요?’에서 사용자가 이어가기를 눌러야 현재 위치를 요청한다. 자동 추적·카메라 시작은 하지 않는다.
- 새 GPS 오차30m 이하를 확인해 저장 경로의 현재 진행값을 계산한다. 경로 밖이거나 투영 불가하면 기존 목적지로 새 경로를 요청하고 성공 시에만 안내를 시작한다.
- 권한 거절·통신/위치 오류는 저장 안내를 보존해 재시도한다. 중복 요청·30초 응답 제한·삭제·다른 화면 이동·탭 숨김·해제 시 늦은 응답을 무효화한다.
- 종료·도착·직접 삭제 시 저장 기록을 제거한다. 새 안내/재탐색 시 최신 경로로 교체한다.
- 24시간 이내 기록만 복원한다. 만료/깨진 JSON/다른 버전/잘못된 좌표·거리·단계/큰 데이터는 다음 실행 시 제거한다. 브라우저를 닫은 동안 자동 삭제 시각을 보장하지 않으므로 UI도 ‘하루 이내 안내만 이어가기’로 표현한다.
- 저장·삭제 실패는 화면에 알린다. 저장 실패 시 이전 기록 삭제도 시도하되 저장소 접근이 막히면 남아 있을 수 있음을 알린다. 기존 안내는 계속된다.
- 저장 경로는 위치 정보이므로 README와 이용 기록 문서의 저장 범위를 갱신한다. 시안 데이터와 키를 공유하지 않는다.
