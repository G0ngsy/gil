# 카메라 시야 확보·도착 표현·지도 안내 고정 (2026-11-18)

## 문제
사용자 실외 녹화에서 카메라 위 큰 중앙 카드와 반복 설명이 실제 길을 가렸다. 지도 안내 카드가 영상 초반 보이지 않았으며, 도착 안내 후 실제 출입구까지 몇 걸음 더 필요했다고 사용자가 보고했다.

## 원인
카메라에 제목·중앙 안내·설명·큰 하단 패널이 중복됐다. 지도 안내와 카메라가 스크롤되는 본문 안에 있어 본문의 스크롤 위치에 영향을 받았다. 경로 도착점과 실제 장소 출입구는 일치한다고 보장할 수 없는데 일반 도착 문구가 확정적으로 읽혔다. 사용자의 몇 걸음과 화면상 POI 좌표 차이68m는 동일한 측정값이 아니다.

## 해결방법
- 카메라는 상단 작은 경로 안내와 하단 정보·지도 보기 버튼만 유지. 반복 설명과 안전 안내는 정보 창으로 이동했다.
- 카메라를 별도 고정 영역에 표시하고 뒤의 본문은 조작되지 않게 처리했다. 권한 대기·취소·오류·재시도와 영상 자원 해제는 유지했다.
- 지도 안내를 스크롤 본문 밖에 고정. 지도 연결 실패 시에도 안내 카드와 본문이 겹치지 않도록 공간을 확보했다.
- 지도·카메라·홈의 도착 문구를 ‘목적지 근처에 도착했어요’로 변경하고 실제 출입구 확인을 요청한다. 도착 시 남은 거리는 ‘경로 끝 기준’으로 표시한다.
- 도착 임계값·GPS 진행 계산은 변경하지 않았다. 사진 인식/VPS/실제 도로에 고정된 AR은 이번 범위가 아니다.
