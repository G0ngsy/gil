# TMAP AppKey 지도 공용 사용

## 문제
사용자가 동일 AppKey 사용을 요청했으나 기존 설정은 서버/지도 키가 같으면 거부하고 지도 설정을 비워 두었다.

## 원인
별도 키 분리를 필수로 가정한 빌드 정책이 적용되어 있었다.

## 해결방법
사용자 지시에 따라 TMAP_APP_KEY를 웹 지도 SDK 인증에도 우선 전달하도록 변경했다. 동일 키 거부 조건을 제거했다. AppKey가 없을 때만 기존 VITE_TMAP_MAP_KEY를 호환 설정으로 사용한다. 실제 값은 출력·커밋하지 않는다. 브라우저 지도 인증 값은 공개된다는 점을 설정 문서에 명시했다. 키 변경 시 재빌드 필요.

## 결과
빌드·단위 109개·지도 로더/모바일 배치 5개 통과. 가짜 키로 공용 키 우선순위와 동일 키 허용 검증. 실제 배포 지도는 후속 확인 기록 참조. API 사용 제한 설정·실외 위치 정확도는 별도 미확인. AI 지원 구현.
