# 종료 화면을 기존 시안으로 정렬 (2026-11-26)

## 문제
실제 안내 종료 화면이 기존 도착 시안과 달리 간소한 체크·문구·홈 버튼으로 구현되어 사용자 기대와 달랐다.

## 원인
종료 흐름 추가 때 별도 UI를 만들고 기존 arrival 디자인을 재사용하지 않았다.

## 해결방법
연꽃 구분선·큰 녹색 체크·명조 제목·목적지 아이콘·안내 마치기·다른 목적지 찾기·선택 평가/단청 감사 표시를 기존 시안과 동일한 스타일로 구성한다. 제목은 중도 종료를 고려해 길 안내를 마쳤어요로 구분하고 실측하지 않은 이동 거리/소요 시간은 표시하지 않는다. 평가는 저장/전송하지 않는 로컬 선택이며 새 종료 때 초기화한다. GPS/카메라 해제·뒤로가기 홈 이동/이전 경로 무효화는 유지한다.

## 결과
빌드 통과. 브라우저·캡처·배포 결과는 아래 기록한다. 모의 API/GPS 검증, 실기기 확인 별도. AI 지원 구현·검증·기록.

검증: 관련 브라우저19개 통과. 캡처에서 flex 항목의 auto 가로 여백으로 본문이 좁아져 width100%를 명시한 뒤 작은 화면/200% 글씨·평가2개 재검증 통과.390px 캡처를 시각 검토했다(모의 API/GPS).
