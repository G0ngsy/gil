# 경로 도착점 라벨 너비와 시작 아래 문구 정리

## 문제
지도에서 경로 도착점 박스가 짧은 글자에 비해 길게 표시됐다. 사용자는 길 안내 시작 아래 도착점/장소 차이 설명도 제거해 달라고 요청했다.

## 원인
라벨에는 경로 도착점을 표시하면서 박스 너비는 destination.name 길이로 계산했다. 긴 장소명을 선택할수록 관련 없는 여백이 생겼다.

## 해결방법
실제 표시 문구(말줄임 포함)를 SVG와 같은 bold12px sans-serif로 측정해 좌우 여백24px을 더한다. 최소76px을 적용하고 측정 기능이 없으면 글자 수로 대체한다. 사용자가 표시한 시작 아래 차이 안내 본문과 사용하지 않는 스타일/계산을 제거했다. 경로 도착점·장소 위치 마커, 상세 타임라인과 실제 출입구 확인 문구는 기존 위치에서 유지한다.

## 결과
최종 빌드 통과. 지도/바텀시트/검색27개 통과(모의 API/GPS/지도 SDK). 경로 도착점 마커 폭100px 미만·정확한 좌표/장소 마커 유지·차이 본문 없음·상세 펼침을 확인했다.360/390/430px 배치와360×640/200% 글씨 접근성 포함. 실제 지도/실기기 확인은 별도. CSS 정리 중 남은 상위 선택자를 diff 검토로 제거하고 최종 빌드를 재확인했다. AI 지원 수정/검증. [하단 화면](../portfolio/assets/2026-11-26-route-copy-removed-390.png)은 모의 지도 배치 캡처이며 실제 지도 라벨 사진은 아니다.
