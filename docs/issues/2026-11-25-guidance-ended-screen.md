# 안내 종료 화면과 뒤로가기 (2026-11-25)

## 문제
안내 종료를 확정하면 바로 홈으로 돌아가 종료 결과를 확인하기 어려웠다. 사용자는 별도 종료 화면을 요청했다.

## 원인
finishGuidance가 GPS·요청·복원 데이터 정리 뒤 home 이동만 수행했다. 종료 결과를 표시할 화면 상태가 없었다.

## 해결방법
실제 안내 종료 후 ended 화면을 표시한다. 목적지명만 결과 화면에 유지하고 GPS·카메라·경로·복원 저장은 해제한다. 도착을 의미하는 문구 대신 '길 안내를 종료했어요'를 사용한다. 홈으로/다른 목적지 찾기는 홈 검색 화면으로 이동한다. 방문 기록을 새 세션의 홈→종료 화면으로 구성해 뒤로가기 시 홈으로 이동하고 종료된 경로를 되살리지 않는다. 종료 확인 취소는 안내를 유지한다. 실제 안내가 없는 경로 확인 종료와 새 목적지 안내 교체는 기존 흐름을 유지한다.

## 결과
빌드 통과. 초기 회귀에서 이전 홈 이동을 기대하던 테스트가 실패해 새 종료 화면 기준으로 수정했다. 최종 브라우저·배포 결과는 아래 추가한다. AI 지원 구현·자동 검증·문서 작성. 모의 API/GPS 검증과 실기기 검증을 구분한다.

## 뒤로가기 사용자 흐름
- 카메라: 카메라를 닫고 지도로, GPS 안내는 유지.
- 지도: 이전 경로 확인 화면으로. 경로 확인: 이전 검색 결과로. 검색 결과: 진입했던 홈 또는 이용 기록으로.
- 기록·개인정보: 방문했던 이전 화면으로.
- 종료 확인창: 창만 닫고 기존 화면·안내 유지.
- 지도 X: 화면만 홈으로 닫고 안내 유지.
- 안내 종료 확정: 자원/복원 기록 정리→종료 화면. 종료 화면 뒤로가기: 홈.
- 홈: 브라우저의 기본 뒤로가기(이전 사이트 이동 또는 실행 환경에 따른 동작). 웹에서 앱 강제 종료를 보장하지 않는다.

검증: 빌드 통과. 초기 관련43개 중42개 통과(이전 홈 기대1개), 기대 수정 후 해당1개 통과. 뒤로가기9개(신규 작은 화면/200% 글자 포함) 통과. 총 관련44개 시나리오를 확인했다. 모의 API/GPS 기반이며 실기기 확인은 별도다.
