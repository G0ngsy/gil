# 현재 위치 카드 전체 버튼

## 문제
현재 위치 제목/확인 요청/같은 이름의 버튼과 핀/위치 아이콘이 함께 반복되어 복잡했다.
## 원인
상태 설명과 행동을 별도 작은 버튼으로 나눠 배치했다.
## 해결방법
사용자가 선택한1번 시안처럼 위치 아이콘·한 줄 문구·꺾쇠로 단순화하고 카드 전체를 버튼으로 만들었다. 확인 전 현재 위치 확인, 확인 후 실제 주소를 표시한다. 긴 주소는 줄바꿈, 조회 중 비활성화/기존 주소·이전 확인 상태/오류와 재시도는 유지한다. 접근 가능한 동작 이름은 현재 위치 확인/다시 확인을 유지한다.
## 결과
빌드·위치/회귀/검색20개 통과, 캡처 추가 후 주소 확인/주변 검색 단독1개 재통과. 모의 GPS/API 검증이며 자동 권한 요청 없음·주소 갱신·조회 실패·기존 주소 보존·좌표 저장 없음·검색 범위를 확인했다.390px 확인 전후 캡처를 시각 검토했다. 실기기 터치/권한 검증은 별도. AI 지원 수정.
