# 실제 검색 경로의 GPS 이동 안내 연결

## 문제
실제 검색 모드는 경로 전체 정보만 표시했고 GPS 진행 계산은 테스트 모드에서만 사용했다. 공통 GPS 훅의 수신 문구도 예시 경로용이었다.

## 원인
실제 경로 상태와 선택형 GPS 추적·진행 상태·지도 위치 표시가 연결되지 않았다.

## 해결방법
실제 API에서 받은 WalkingRoute를 기존 진행 계산에 전달했다. GPS 이동 안내 시작/중지, 남은 거리, 단계 자동 전환, 이탈/복귀, 정확한 표본 2회의 도착 확인을 연결했다. GPS 수신 문구는 호출 화면에서 지정하며 예시 모드 기본 문구는 유지한다. 지도 전체를 매 GPS마다 만들지 않고 별도 마지막 반영 위치 마커만 갱신한다.

추적은 명시적 시작만 허용한다. 중지·뒤로 이동·예시 화면 전환·경로 변경/초기화·탭 숨김·페이지 이탈·컴포넌트 해제·도착 때 수신을 해제한다. 늦은 콜백은 기존 세션 토큰으로 무시한다. 재시작은 새 GPS와 초기 진행 상태로 시작한다. 전체 경로 시간은 그대로 전체 기준으로 표시하며 남은 시간을 임의 계산하지 않는다. 빈 안내 단계는 문구를 만들지 않고 지도 확인 안내를 사용한다.

## 결과
단위 테스트와 실제 화면의 모의 API/GPS 브라우저 검증으로 연결을 확인한다. 신규 검증은 자동 시작하지 않음, 거리 감소·단계 전환·이탈/복귀·2회 도착과 자동 해제, 중지·재시작·뒤로 이동·늦은 콜백 무시를 다룬다. 기존 GPS 훅 검증은 권한 오류·부정확/오래된 좌표·수신 중단·탭 숨김을 포함한다. 최종 개수/결과는 아래에 기록한다.

## 미확인
이번 연결은 모의 API/GPS 검증이며 실외 정확도·최신 배포·휴대폰 GPS 동작 확인이 아니다. 이전 실제 TMAP 검색/지도 검증과 구분한다. 자동 재탐색, 카메라 안내, 실제 경로의 방위 센서 카드는 이번 범위에 포함하지 않았다. 지도 위치 표시는 마지막 반영 좌표이며 수신 중지 후 실시간 위치로 해석하지 않는다. 위치를 앱 저장소에 누적하거나 매 GPS마다 경로 API를 호출하지 않는다.

코드 기준: 535d2d1 이후 본 작업 트리. AI 지원으로 연결·검증·문서화를 수행했다.

회귀 실행 중 기존 시안 recheck 닫기/복귀 검증이 자동 camera 전환 타이머와 경합해 실패했다. 제품 동작은 변경하지 않고 해당 테스트의 시계를 고정해 닫기/복귀 대상 화면을 유지했다. 수정 범위는 해당 테스트 재실행으로 확인한다.

최종 검증: 단위 100개 통과, 최종 빌드 통과. 브라우저 37개 범위에서 36개 통과/시안 타이머 경합 1개 실패 후 해당 테스트를 수정해 단독 재실행 1개 통과. 전체 37개를 수정 후 일괄 재실행한 것은 아니다. 문서 링크 171개와 변경 형식 검사 통과. React 검토에서 센서 수명주기·effect 의존성·지도 전체 재생성 방지·상태 알림을 확인했다.
