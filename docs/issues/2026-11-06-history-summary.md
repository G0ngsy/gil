# 홈 기록 요약과 전체 기록 화면 분리

## 문제
홈에서 최근 검색·목적지 전체와 삭제 관리가 표시되어 기록이 늘수록 홈 스크롤이 길어졌다.

## 원인
전체 기록 관리 컴포넌트를 요약 없이 홈에 직접 배치했다.

## 해결방법
홈은 최근 목적지 1개와 기록 자세히 보기 버튼만 제공한다. 상세 화면에서 최근 검색·전체 목적지·개별 삭제·전체 삭제를 제공한다. 예시/실제 모드에 동일하게 적용하고 기존 저장 데이터는 유지한다. 홈 목적지 이름·주소는 한 줄 말줄임으로 높이를 제한한다. 상세에서 삭제한 뒤 홈으로 돌아오면 다음 최신 목적지가 표시된다.

## 결과
빌드·브라우저 테스트 35개 통과 및 실제 배포에서 요약·상세·삭제·홈 복귀 확인. 검증 문서에 기록했다. 실제 검색 모드의 키 미설정 시 재검색 실패도 상세 화면에서 안내한다.
