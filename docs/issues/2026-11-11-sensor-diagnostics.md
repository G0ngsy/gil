# 갤럭시 방향 센서 진단

## 문제
사용자 갤럭시 화면에서 상대 방향 안내 뒤 수신 중지 문구가 나타났다. 화면만으로는 제공 필드와 실제 이벤트 종류를 확인할 수 없었다.

## 원인
방향 변환은 신뢰 가능한 방위·오차·자세 조건을 요구하지만, 기존 UI는 실제 입력과 제외 사유를 보여주지 않았다. 유효하지 않은 이벤트를 수신한 경우도 시간 초과 시 센서 수신 중단으로 표현했다. 갤럭시의 정확한 제공 값은 아직 미확인이다.

## 해결방법
카메라 안내의 접힌 ‘센서 진단’에 최신 이벤트 종류, absolute/alpha/beta/gamma, webkit 방위/오차, 화면 각도, 변환 제외 사유를 표시하는 수동 결과 확인·복사 기능을 추가했다. 미제공·비정상 숫자는 null로 표시한다. 브라우저 정보만 함께 포함하고 좌표·주소·영상은 제외한다. 메모리에서만 유지하며 별도 저장·자동 전송하지 않는다. 복사 실패 시 선택 가능한 읽기 전용 결과를 제공한다. 유효하지 않은 이벤트를 수신한 경우와 아무 이벤트도 받지 못한 경우의 시간 초과 문구를 구분한다. 기존 방향 허용 조건은 완화하지 않았다.

## 결과
빌드, 단위 테스트 109개, 관련 브라우저 테스트 15개 통과. 모의 이벤트에서 정확도 제외·상대 방향 필드·복사 성공/실패·위치정보 제외·센서 해제를 확인했다. 사용자 갤럭시의 실제 진단 결과와 화살표 지원 개선은 미확인이다. AI 지원 구현·검증.
