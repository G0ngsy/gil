# 기존 문 연출 개선안 미리보기

## 문제
사용자가 기존 문 열림 스플래시의 개선점을 움직이는 미리보기로 확인하고자 했다. 원본 가로 문 이미지를 세로로 늘리면 문고리/창살 비율이 변하고 기존 재생은 4.55초였다.

## 원인
기존 문은 object-fit:fill로 이미지를 뷰포트에 맞추고 로고와 홈 전환을 긴 시간표로 실행했다. 가로 풍경을 cover로 채우면 양쪽 소나무·처마도 잘릴 수 있었다.

## 해결방법
intro=refined에서만 실행하는 RefinedIntro를 추가했다. 밝은 갈색 CSS 프레임·일정한 창살 굵기·23px 원형 문고리로 비율을 유지한다. 풍경은 원본 비율을 유지하며 홈과 같은 폭/상단 영역을 사용하고 가장자리는 정적인 투명도 마스크로 한지색에 연결한다. 0.3초 대기→1.1초 문 열림→0.9초 로고→0.7초 홈 페이드/98%→100% 확대, 총3초다. 건너뛰기·동작 줄이기·타이머 정리를 지원한다. 미리보기는 splashSeen/기존 세션 기록을 바꾸지 않고 기본 매듭·세 걸음·기존 문 연출을 유지한다.

## 결과
빌드 및 개선안/기본 스플래시 관련16개 통과. 배경 경계 최종 조정 후 빌드 및 개선안4개 재통과. 360/390/430px 원형 비율·단독 재생·로고→홈·기록 보존·스킵·동작 줄이기를 확인했다. 코드로 그린 비율/속도 비교용 문이며 기존 수채 질감을 그대로 복제한 자산은 아니다. 실기기 성능 미측정, API/GPS 검증 범위 아님. 사용자 요청에 따른 AI 지원 구현.
