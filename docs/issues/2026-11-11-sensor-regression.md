# 최신 센서 전체 회귀와 배포 준비

## 문제
1d6e986 기준 전체 브라우저 테스트에서 79개 중 78개 통과, 방향 오차/자세/수신 중단 검증 1개가 실패했다. 단독 3회 실행에서도 2회 실패했다. -1 오차를 주입한 뒤 기대한 오차 안내가 아닌 자세 안내가 표시됐다.

## 원인
주입 테스트가 실제 Chrome의 기본 센서 이벤트도 같은 리스너에서 받았다. 실제 장치가 없는 브라우저의 초기 null 값 이벤트가 주입한 결과와 경합할 수 있었다. 자동화의 입력 격리가 부족한 문제로 판단했고, 테스트 fixture에서 trusted 기본 이벤트를 제외한 뒤 반복 검증했다. 제품 센서 코드는 변경하지 않았다.

## 해결방법
heading.spec.ts의 센서 이벤트 등록 wrapper에서 주입한 이벤트만 전달하고 removeEventListener도 동일 wrapper를 제거하도록 매핑한다. 실제 제품은 trusted 이벤트를 정상 수신한다. 오차/자세 거부·시간 초과·리스너 해제 검증은 그대로 유지한다. 실패 항목 반복 5회 통과 후 전체 회귀를 다시 실행한다.

## 결과
단위 100개와 빌드 통과. 수정된 실패 항목 5회 반복 통과. 수정 후 전체 79개 통과 및 9150069 원격 배포/실제 REST 확인 완료. 전체 회귀 및 원격 배포의 최종 결과는 docs/validation-2026-11-11-release.md에 기록한다. 센서 이벤트 주입은 실기기 나침반 정확도의 증거가 아니다.
