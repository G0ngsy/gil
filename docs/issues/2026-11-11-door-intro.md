# 문 열림 인트로 (2026-11-11)

## 문제
닫힌 한옥문과 중앙 로고가 함께 갈라지고 첨부 배경을 거쳐 홈으로 진입하는 연출이 필요했다. 작업 폴더는 오래된 버전이었고 회귀 검증에서 실제 카메라 코드까지 모의 코드로 간주하는 과거 검사가 실패했다.

## 원인
기존 진입점에는 인트로가 없었다. 로고를 단일 고정 요소로 만들면 문과 함께 나뉘지 않는다. 이전 카메라 연결 작업 이후 CameraPreview는 실제 기능에도 사용되지만 검사 목록은 갱신되지 않았다.

## 해결방법
원격 최신 5d2fc64에서 전용 브랜치를 만들었다. 앞서 생성한 문 이미지와 사용자가 첨부한 풍경을 사용한다. 같은 전체 문 이미지와 로고를 각각 좌우 절반에 잘라 배치하고 동일한 이동으로 벌린다. 0.55초 대기, 1.55초 열림, 0.6초 배경 페이드 후 기존 홈을 드러낸다. 이미지 디코딩 대기에는 1.5초 상한을 두고 실패해도 홈 진입을 보장한다. 인트로 중 홈은 inert 처리한다. 건너뛰기·동작 줄이기·세션 최초 1회·preview 제외를 지원한다. intro=1은 연출 재확인용이다. 기존 기능 테스트는 reduced-motion 환경으로 실행하고 별도 인트로 검증은 애니메이션을 활성화한다. 모의 코드 검사는 실제 카메라 모듈을 제외하고 DemoApp/SimulationNavigation 유입 검사를 유지한다.

## 결과
검증 결과는 동일 작업의 portfolio/evidence.md에 기록한다. 권한 자동 요청이나 GPS/검색 데이터 변경은 없다. AI 지원으로 구현했으며 실기기 성능은 별도 확인이 필요하다. 사용자 첨부 배경과 대화에서 생성한 문 이미지가 자산 출처다. 홈 배경 자체는 변경하지 않는다.
