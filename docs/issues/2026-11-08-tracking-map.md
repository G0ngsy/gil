# 예시 지도 안내에 이동 추적 상태 연결 (2026-11-08)

## 문제
추적 테스트 화면이 숫자와 문구만 제공해 현재 위치와 경로 진행을 한눈에 확인하기 어려웠다. 안내 시작·종료와 지도 표시도 연결되지 않았다.

## 원인
GPS 진행 상태를 소비하는 지도 컴포넌트와 안내 제어 상태가 없었다.

## 해결방법
- `/?mode=simulation`에 키 없이 동작하는 SVG 경로 도식을 추가했다. 실제 지도·도로 정보가 아닌 고정 예시 경로임을 화면에 명시한다. TMAP 지도와 실제 검색 모드는 변경하지 않는다.
- 전체 경로·이동한 구간·출발/도착·마지막 반영 위치를 표시한다. 이탈 중 이동 구간을 유지하고 위치 원의 색을 변경한다. 거부된 좌표는 위치 원에도 반영하지 않는다.
- 전체 경로 보기와 현재 위치 보기로 표시 범위를 전환한다. 현재 위치가 경로 범위 밖이면 안내 문구를 표시하고 현재 위치 보기를 제공한다.
- 모의 지도 안내 시작·종료를 추가했다. 종료는 GPS 추적을 해제하고 위치·이동 구간·거리 상태를 초기화한다. GPS 시작 역시 새 안내로 초기화하며, 중지·수신 실패 후에는 마지막 위치임을 표시하고 현재 이동 지시를 숨긴다.
- 실제 GPS에서 모의 입력으로 전환할 때 진행을 초기화해 서로 다른 좌표원의 상태를 섞지 않는다. 모의 좌표 버튼은 기존처럼 모의 안내를 시작하며 이동 상태를 갱신한다.
- 한지색 카드와 진녹색 이동 구간, 청록색 전체 경로를 사용했다. SVG 제목·영역 이름·버튼 선택 상태를 제공한다. 경로 도식에 장식을 덧붙이지 않는다.

- 최초 모바일 시나리오는 회전 구간을 건너뛰어 먼 복귀 거부 조건에 걸렸다. 정상 이동 순서로 시나리오를 수정했고 기존 점프 거부 조건은 유지했다.

## 결과
- 검증: 단위 테스트 34개, TypeScript 검사·프로덕션 빌드 통과.
- 브라우저·화면 검증: 추적 브라우저 테스트 15개 통과. 360·390·430px에서 가로 넘침 없음, 위치·이동 구간·이탈/복귀·표시 범위 전환·종료 후 늦은 GPS 무시·수신 중단·좌표원 변경을 확인했다. 360px 캡처를 직접 열어 경로·위치·범례·버튼·안내 카드의 표시를 확인했다.
- 미확인: 실제 기기·실외 보행, TMAP 키·실제 지도·실제 경로·재탐색 연동. 실제 검색 모드의 지도 기반 연속 안내는 아직 연결하지 않았다.
- 제한: 이동한 구간은 마지막으로 반영한 경로 진행 위치까지의 표시이며 GPS 원시 궤적이 아니다. 역방향 이동 시 길이가 줄어들 수 있고, 이탈 중에는 경로상 진행을 유지한다. 실제 GPS 수신 좌표는 고정된 서울시청 인근 예시 경로와 비교하는 테스트에만 사용한다.

## 확인 방법
`/?mode=simulation`에서 모의 지도 안내 시작 → 출발 → 직진 이동 → 회전 지점 → 다음 안내 → 경로 이탈 → 경로 복귀 → 도착(두 번)을 선택한다. 현재 위치 보기와 전체 경로 보기로 표시 범위를 바꾸고 지도 안내 종료 시 위치 원과 이동 구간이 지워지는지 확인한다. 실제 GPS는 별도의 시작 버튼으로만 요청한다.
