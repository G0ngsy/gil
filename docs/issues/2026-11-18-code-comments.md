# 기능별 코드 주석 (2026-11-18)

## 문제
파일/함수의 역할과 실제·검토 모드, 화면 닫기·안내 종료 등 상태 구분을 처음 읽는 사람이 파악하기 어려웠다.

## 원인
기능별 설명이 일부 영어 주석이나 외부 작업 기록에만 있었고 핵심 조정 함수가 한 파일에 모여 있었다.

## 해결방법
소스39개 파일 상단에 한국어 역할 설명을 추가하고 검색·위치·GPS·지도·카메라·복원·재탐색·뒤로가기·서버 응답의 주요 함수와 상태 구분에 주석을 추가했다. [코드 읽는 순서](../code-guide.md)도 작성했다. 동작 변경이나 코드 재구성은 하지 않았다.

## 결과
TypeScript 파서에서 주석을 제거한 출력이 변경 전과 동일한지39개 파일 비교. 빌드·단위133개 통과, 출력 JS/CSS 번들 이름과 크기도 이전과 동일. 설명 추가만 있어 브라우저/실기기 검사를 중복 실행하지 않았다. AI 지원 주석·문서 작성 및 검증.
