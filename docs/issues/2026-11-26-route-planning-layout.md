# 경로 확인 버튼 아이콘과 지도 높이 정리

## 문제
도보 경로 찾기 아래 빈 시트가 남고 지도 높이는 고정되어 있었다. 경로 계산 뒤 길 안내 시작 아래의 출입구 차이 안내와 상세 제목이 화면 아래로 밀려 내용을 알아보기 어려웠다. 사용자는 두 행동 버튼에 종이비행기 아이콘을 요청했다.

## 원인
지도54dvh 고정과 시트 flex:1이 함께 적용되어 시트가 빈 공간을 차지했다. 계산 뒤 목적지/시간/여백/안내 박스가 누적되면서 전체 페이지가 길어졌다.

## 해결방법
공통 SVG에 send 아이콘을 추가하고 실제 경로 찾기/시작 버튼에 적용했다. 시작 전 journey-planning 상태를 분리해 시트는 내용 높이만 사용하고 나머지는 지도에 할당한다. 지도 최소180px과 시트 최대65%를 두어 상세가 길면 시트 안에서 스크롤한다. 계산 결과 내부 위 여백/시간 설명 간격을 줄이고 도착점 차이 안내는 박스 대신 짧은 본문으로 표시한다. 전체 경로 상세는 구분선 있는 접힘 제목으로 유지한다. GPS 안내 중/카메라/지도 실패 상태는 기존 동작을 유지한다.

## 결과
빌드 통과, 지도·바텀시트·지도 실패·검색26개 통과. 추가 배치4개 포함 지도13개 재통과(기존9개 중복).360/390/430px에서 계산 전 버튼 아래 여백18px 이하/지도 높이, 계산 후 시작·출입구 안내·상세 제목 노출, 펼침 후 지도 최소 높이를 검증했다.360×640/글씨200%에서도 스크롤로 시작·상세 접근, 가로 넘침 없음. 모의 API/GPS/SDK이며 실제 TMAP·실기기 보행 검증은 아니다.390px 계산 전후 캡처를 시각 검토했다. React 품질 검토: 아이콘은 aria-hidden, 버튼 이름과 이벤트/세션은 유지, 추가 훅/라이브러리 없음. AI 지원 구현/검증.

작업 중 PowerShell 치환 문자열의 ${...} 해석으로 LiveNavigation 임시 편집이 손상되어 첫 빌드가 실패했다. 깨끗한 HEAD 원본을 복원하고 해당 두 부분만 문자로 치환한 뒤 빌드/관련 흐름을 재검증했다. 최종 diff는 상태 클래스·아이콘 두 부분이다.
