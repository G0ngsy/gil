# 홈 수채 배경 교체

## 문제
사용자가 인트로에 사용한 첨부 풍경을 현재 홈 배경으로 교체하도록 요청했다.

## 원인
홈은 기존 SVG 처마·나뭇가지와 별도 창살 장식을 사용해 인트로의 첨부 수채 이미지와 달랐다.

## 해결방법
실제 홈과 시안 홈의 장식을 같은 intro-landscape.png CSS 배경으로 교체했다. 원본 비율을 유지하고 검색/제목 위아래에 한지색 그라데이션을 적용해 이미지 상단 경계를 완화했다. 검색 범위·현재 위치·최근 기록은 유지했다.

## 결과
빌드와 360/390/430px 브라우저 검사 3개 통과. 배경 적용·기존 SVG 제거·현재 위치 버튼 노출·검색 전환·가로 넘침을 확인했다. API는 모의 응답이며 실제 센서 검증은 이번 변경 범위가 아니다. 첨부 이미지를 재사용했고 AI 지원으로 UI를 수정했다.
