# 실제 카메라 미리보기

## 문제
기존 카메라 안내는 거리 사진만 표시한다. 단순히 영상을 대체하면 시안의 가상 화살표·남은 거리와 실제 영상이 혼합되며, 화면을 벗어나도 카메라가 계속 켜질 수 있다.

## 원인
카메라 권한·영상 스트림 수명 관리가 없고 시안 안내와 실제 영상이 구분되지 않았다. 권한 요청은 사용자가 답하지 않으면 끝나지 않을 수 있다.

## 해결방법
사용자가 실제 카메라 켜기를 눌렀을 때만 getUserMedia를 요청한다. 후면 카메라를 선호하되 장치가 없으면 사용 가능한 카메라를 사용하고 마이크는 요청하지 않는다. 실제 미리보기는 가상 회전·거리·시간을 가리고 방향 추적 미구현을 표시한다. 권한 오류·장치 없음·사용 중·지원 여부·보안 연결을 구분한다. 취소·화면 전환·탭 숨김·pagehide·트랙 종료 시 해제하며 취소 뒤 늦게 수신된 스트림도 즉시 해제한다. 영상은 로컬 video.srcObject로만 재생하고 저장·전송하지 않는다.

## 결과
자동화 검증은 Chrome 가상 카메라 및 오류 모의로 수행한다. 실제 휴대폰·후면 카메라·운영체제 권한 창과 AR 방향 추적은 검증하지 않았다. 실제 영상은 카메라 화면의 별도 버튼으로 사용하며 키가 필요 없다.

## 검증 코드 타입 오류

- 문제: 테스트 추가 후 빌드에서 videoWidth 속성 오류가 발생했다.
- 원인: 브라우저 테스트의 요소 타입이 일반 HTML/SVG로 추론되어 video 속성을 읽을 수 없었다.
- 해결방법: video 선택 요소를 HTMLVideoElement로 명시했다.
- 결과: 빌드 재실행 통과, 카메라 테스트 10개 재실행 통과.
