# 지도 위치·경로 구분과 따라가기

## 문제
지도 연결 후 출발지와 목적지가 비슷한 핀으로 보였고 현재 위치는 기본 마커였다. 지나온 경로 구분·위치 따라가기 동작이 없었다. 위치 버튼은 현재 위치 대신 출발지를 중심으로 지도를 다시 생성했다.

## 원인
전체 경로 확인만을 위한 초기 지도 구현에 GPS 마커 갱신이 추가되어 표시 위계와 안내 중 상호작용이 분리되지 않았다.

## 해결방법
실제 TMAP 지도는 유지하고 현재 위치를 파란 원/흰 테두리, 목적지를 녹색 깃발 핀/이름, 출발지를 회색 작은 원으로 구분했다. 실제 GPS 오차 반경만 옅은 파란 원으로 표시한다. 유효한 GPS가 10초 이상 갱신되지 않거나 안내가 멈추면 회색 마지막 위치로 바꾸고 정확도 원을 숨긴다. 경로 진행값을 실제 선분 길이에 적용해 청록 남은 경로·회녹색 지나온 경로를 밝은 외곽선과 함께 표시한다. 분리 선분을 잇지 않는다. 지도를 드래그/휠 조작하면 따라가기를 멈추고 위치 버튼으로 재개한다. 위치 변화로 지도 인스턴스를 재생성하지 않는다. 마커 좌표 기준점(offset)은 공식 SDK 코드와 대조해 원 중심/핀 끝에 맞췄다.

지도 영역 확대, 상단 이동 안내 카드, 하단 남은 거리·목적지·카메라 버튼으로 구성했다. 가상의 남은 시간을 표시하지 않는다. 실제 전체 예상 시간은 경로 확인 화면에서 유지한다. 카메라 중첩 배치와 기존 장식/선택 강조/사용자 문구 변경을 보존했다.

## 결과
단위 테스트 111개와 세 모바일 크기 지도 모의 SDK 검증 3개 통과. 전체 브라우저·실제 배포 검증 결과는 후속 기록 참조. 모의 SDK 검증은 실제 GPS 정확도나 실외 사용성 검증이 아니다. AI 지원 구현·검증.
