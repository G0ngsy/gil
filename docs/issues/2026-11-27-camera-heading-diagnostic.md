# 카메라 자세 진단 나침반 (2026-11-27)

## 문제
원본 방향 값만으로 세운 후면 카메라 방향을 확인하기 어려웠다. 진단 화면에 계산값·나침반을 요청했다.

## 원인
기존 화면은 상대/절대 이벤트의 원본 값만 표시하고 후면 카메라 -Z의 수평 투영과 화살표가 없었다.

## 해결방법
W3C Z-X-Y 회전 순서로 후면 -Z 벡터를 계산해 수평 방위·고도각·수평 투영을 표시한다. flatHeading도 별도 표시한다. absolute=true의 유효 표본만 채택하고 상대 이벤트가 덮어쓰지 않게 한다. 세로 화면만 지원하며 horiz<0.3·1초 초과 미수신·중지/권한 취소 시 화살표를 숨긴다.100ms 타이머로 만료를 검사한다. 최단각/시간 기준 보간(tau0.2)과 공백 재초기화를 적용한다. N 화살표는 카메라 정면 기준 센서 북쪽을 가리킨다. GPS/카메라/실제 경로 연결·진북 보정·오차 정확도 판정은 추가하지 않았다. 계산값/표시 상태/나이를 기존 수동 복사 결과에 포함한다.

## 결과
최신 원격18커밋을 fast-forward했다. OCR 의존성 누락으로 prebuild가 실패해 npm ci 후 빌드 통과. 단위145개·진단 브라우저4개 통과. 캡처 중 데스크톱 자동 null 이벤트 경합을 가상 테스트에서 격리한 뒤 자세/만료1개 재검증 통과. 수식 기준 방향·359/0·반대각·시간 간격·눕힘·상대 값·센서 중단·중지·복사 검증. 모의 센서로, 실제 갤럭시 자세/자기장/방위 정확도는 미확인. AI 지원 구현·검증·문서.
