# 스플래시 총 시간 설명 불일치

## 문제
사용자가 문 열림→로고→홈 총3초라는 안내와 실제 경험이 다르다고 보고했다.

## 원인
기본/기존 문/개선안 주소가 다르고, 연출 시간과 초기 페이지 로딩을 합친 시간을 구분하지 않았다. 운영 실측은 개선안 연출3.009초·로딩 포함약4.4초, 기존 문연출약6.0초였다.

## 해결방법
운영 주소별 프레임 시간을 측정하고 소스의 분기·타이머·이미지 대기와 대조했다. 기본 채택은 미승인 상태이므로 제품 코드는 그대로 유지하고 잘못 전달한 기준을 정정했다.

## 결과
[측정 조건·수치·제한](../validation-2026-11-26-splash-timing.md)을 기록했다. 개선안3초는 연출 시작 기준이며 네트워크를 포함한 총 대기 보장이 아니다. 코드 변경 없음, 실기기 성능 일반화 불가. AI 지원 확인.
