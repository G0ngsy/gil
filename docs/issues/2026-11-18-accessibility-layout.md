# 접근성·작은 화면·큰 글씨 점검 (2026-11-18)

## 문제
고정 px 글자 크기가 브라우저 기본 글자 크기 확대를 따르지 않았고 검색 아이콘/검색 범위의 조작 크기가 작았다. 새 화면 진입 후 키보드 초점이 명시적으로 이동하지 않았고 카메라 설명은 높이 제한/두 줄 생략에 의존했다. 긴 장소명·글자 확대 조건의 회귀 검사가 없었다.

## 원인
일반 휴대폰 크기의 기본 글씨만 중심으로 스타일이 구성돼 있었다. 고정 높이와 줄 생략, 유연하지 않은 행 배치가 큰 글씨 조건에서 내용을 가릴 가능성이 있었다.

## 해결방법
- CSS 글자 크기를 rem으로 바꿔 브라우저 기본 글자 크기를 따른다. 기본16px 기준 기존 크기를 유지하며 검색 입력은16px로 조정한다. 아이콘 기호는 버튼 안에 들어가도록 별도 상한을 둔다.
- 실제 앱 버튼/선택/상세 토글의 최소 높이를44px로 하고 검색 아이콘 너비도44px로 확보한다.
- 긴 장소명·주소·진행 중 안내와 검색 범위·요약 행을 줄바꿈한다. 헤더는 글자 확대 때 높이가 늘어나도록 하고 기본 안내 헤더52px는 유지한다.
- 카메라 카드의 높이 제한과 설명 생략을 없애고 큰 글씨/작은 높이에서는 세로 이동을 허용한다. 평상시 화면 중앙 비가림 검사는 유지한다.
- 새 화면 이동 시 이름 있는 본문(main)에 초점을 옮기고 버튼/입력/선택/상세 토글에 키보드 초점 테두리를 표시한다. 일부 보조 문구는 공통 글자색으로 통일한다.
- 320/360/430px·글자100/200%·긴 장소명, 버튼 이름과 최소 높이, 키보드 검색 순서, 확인창 초점/Esc, 카메라 정보창 복귀를 검사한다.
