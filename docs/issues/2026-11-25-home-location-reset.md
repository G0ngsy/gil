# 홈 현재 위치 재조회 초기화 (2026-11-25)

## 문제
다른 화면을 갔다가 홈으로 돌아오면 현재 위치 주소가 사라진다는 사용자 제보.

## 원인
위치 재확인 시작 시 좌표·주소를 즉시 null로 지웠다. 재확인 도중 화면 이동으로 요청이 취소되면 대체 좌표를 받지 못하고 빈 상태가 남았다. 실패 때도 기존 좌표를 삭제했다.

## 해결방법
재조회 시작/실패 때 마지막 확인 좌표와 주소를 보존하고 새 좌표 성공 때 주소를 갱신한다. 갱신 중/실패의 이전 확인 위치 표시를 추가했다. 취소/실패 요청은 null을 반환해 기존 값을 새로운 경로 요청의 성공 결과로 대체하지 않는다. 새로고침/앱 재실행용 위치 저장은 추가하지 않았다. 지도 배율 동작은 이번 수정에 포함하지 않았다.

## 결과
빌드·기존 위치검색/취소 회귀11개·신규 재조회 중 화면 이동→홈 복귀 및 권한 실패 보존1개 통과. 모의 GPS/API 검증이며 실제 제보 기기의 재확인은 별도. AI 지원 구현·검증·문서.
