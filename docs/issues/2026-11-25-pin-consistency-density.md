# 진행 표시 밀도와 위치 핀 일관성 (2026-11-25)

## 문제
120m 경로에서 화살표가 하나만 보이고 회색 원이 핀으로 바뀌는 사용자 제보.

## 원인
70m 간격과 회전 주변 제외로 짧은 경로에 표시가 적었다. 안내 전 화면은 회색 원형 출발 마커, 안내 시작 후에는 별도 현재 위치 마커였으며 방향 확정 시 핀에서 삼각형으로 바뀌었다.

## 해결방법
작은 민트 꺾쇠 크기/회전 주변12m 제외를 유지하면서30m 간격·첫15m·최대24개로 조정했다. 출발도 회색 핀과 출발 라벨로 표시하고 현재 위치 수신 뒤 출발 마커를 숨긴다. 현재 위치는 방향 미확인/확인 모두 같은 핀 도형을 사용하고 회전/색상만 바꾼다. 불확실/오래된 위치가 회색으로 보이는 정책은 유지하며 실제 위치로 꾸미지 않는다. 안내 전 범례는 출발이라고 표시한다.
