# 걸어도 지도 위치가 갱신되지 않는 증상 재현

## 문제
사용자가 실외에서 걸어도 지도 위치가 움직이지 않는다고 보고했다. 기종 세대·브라우저·당시 GPS 오차/수신 로그는 미확인이다. 원래 작업 폴더는 원격보다 49개 커밋 뒤여서 기존 미커밋 변경을 건드리지 않고 별도 worktree의 9e32b12 기준으로 조사했다.

## 원인
배포 앱에 공공 좌표의 모의 GPS를 주입했다. 1회 출발 위치는 오차 70m로 받아 경로 화면까지 진입하지만 연속 GPS 훅은 오차 30m 초과를 모두 버렸다. 오차 45m를 넣으면 현재 위치 확인 중에 머물고 지도 위치 마커가 나타나지 않았다. 같은 좌표에서 오차 5m를 넣고 약 22m 이동시키면 남은 거리가 222m에서 200m로 바뀌고 지도도 갱신됐다. 위치 정확도 필터가 표시까지 막는 재현 경로를 확인했으며 사용자의 실제 기기 원인으로 확정하지는 않았다.

## 해결방법
GPS의 지도 관측과 경로 판정 입력을 분리했다. 실제 안내에서는 신선한 오차 30~100m 좌표를 대략적 위치/오차 원으로 표시하고 안내 카드에 오차를 알린다. 회색 마커로 정밀 현재 위치와 구분한다. 관측이 계속 들어오면 수신 중으로 유지하며 실제 수신이 20초 끊기면 기존처럼 중지한다. 시각/좌표가 유효하지 않거나 오차 100m를 넘으면 관측에도 쓰지 않는다.

거리·안내 단계·회전·도착·카메라 방향 비교에는 기존 오차 30m 이하의 검증 입력만 사용한다. 부정확한 GPS로 도착/회전을 꾸미지 않는다. 정확도가 회복되면 정상 안내로 돌아간다. 대략적인 관측이 오래되거나 중지되면 마지막 확인 위치로 남기고 정확도 원과 따라가기는 중단한다. 테스트 모드는 기존 관측 콜백을 사용하지 않으므로 기존 수신 정책을 보존했다.

## 검증
- 배포본 사전 재현: 실제 TMAP 지도 SDK/타일, 장소·경로 API는 모의 응답, GPS는 서울시청 공공 좌표 주입. 390×844 Chrome, 페이지 예외 0개. 사용자 실위치 사용 안 함.
- 수정 로컬 실제 SDK 검증: 오차 45m에서 대략 위치/오차 카드/원 표시, 정확도 5m 회복 및 22m 이동 후 남은 거리 200m. 실제 SDK/타일만 사용하며 경로는 222m 모의 직선이다. 화면은 포트폴리오 근거 목록 참조.
- 단위 120개 및 최종 빌드 통과. 지도/실제 경로/추적 브라우저 26개 통과, 마지막 관측 위치 보존 수정 후 지도 5개 재통과. 최종 세션/카메라 결과는 아래에 기록한다.
- 실제 SDK 로컬 검증 첫 실행은 검증 도중 소스 수정으로 Vite가 페이지를 다시 불러와 주입 콜백을 잃었다. 소스 변경 없이 재실행해 성공했다. 이 실패를 제품 GPS 장애로 분류하지 않았다.

## 제한과 다음
휴대폰 자체 GPS가 정지한 좌표만 보내는 경우·권한/배터리 정책·화면 잠금/탭 전환은 별도 실기기 확인이 필요하다. 이번 모의 이동은 실외 정확도 성과의 증거가 아니다. 푸시와 실제 배포 적용을 구분한다. 기존 AppKey 지도 공용 정책은 원격 최신 사용자 결정 그대로 보존했고 키/인증 URL은 출력하지 않았다.
