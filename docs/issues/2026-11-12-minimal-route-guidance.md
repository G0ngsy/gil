# 지도 중심 안내 화면 정리

## 문제
사용자는 자세히 보기를 없애고 예시 이미지처럼 짧은 회전 안내와 넓은 지도, 간단한 하단 조작을 요청했다. 기존 상단은 긴 제공사 원문이고 지도는 현재 위치를 단순 중심에 놓아 목적지가 상단 카드/화면 밖으로 가릴 수 있었다.

## 원인
상세 단계·위치 정보가 하단 접힘 영역에 남아 있었고 제공사 이동 설명의 고정 거리를 현재 진행 거리와 구분하지 않았다. 지도 따라가기는 전체 경로의 가독성보다 위치 중심 이동만 수행했다.

## 해결방법
실제 경로 확인/안내의 자세히 보기, 단계 목록, 상세 위치 상태를 제거했다. 하단 목적지 카드를 간결하게 만들고 남은 거리 옆 종료/카메라 조작을 보존했다. 상단은 아이콘·짧은 안내·도로명으로 구성한다. 서버에서 제공사의 nextRoadName을 선택적으로 보존한다. 공식 보행자 turnType(직진11/좌12/우13 등)에 따라 경로상 다음 안내점까지의 기하 거리에서 현재 진행값을 뺀 거리를 표시한다. 5m 이내는 지금, 150m 이내는 거리와 회전으로 표시한다. 분리 경로·겹치는 경로의 모호한 안내점·미지원 코드·오래되거나 거부된 GPS에는 회전을 추측하지 않는다. 원문 속 고정 이동 거리는 실시간 남은 거리처럼 표시하지 않고 안전한 짧은 원문 또는 일반 이동 문구를 사용한다.

지도는 앞으로 최대 500m 경로 구간을 카드/목적지/범례 여백과 함께 맞춘다. 드래그/휠 시 따라가기 중단, 위치 버튼 복귀, X 홈 안내 유지와 종료 확인은 보존했다. 위치 수신·이탈·도착 상태는 상단에 표시한다. 이탈은 자동 재탐색 완료를 주장하지 않는다.

공식 회전 코드 출처: https://tmap-skopenapi.readme.io/reference/경로안내-샘플예제 (2026-11-12 확인). 실제 TMAP 바탕지도/REST 경로를 사용하며 도로를 임의로 꾸미지 않는다.
