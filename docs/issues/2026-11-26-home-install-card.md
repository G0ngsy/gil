# 홈 설치 안내 제거

## 문제
홈의 설치 안내 카드가 현재 위치 확인·목적지 검색보다 공간을 크게 차지했다. 사용자는 카드 제거를 요청했다.
## 원인
PwaInstall 컴포넌트가 실제 홈 본문에 포함돼 미설치 브라우저에서 안내가 반복됐다.
## 해결방법
홈의 설치 안내를 제거하고 개인정보·이용 안내 안으로 옮겼다. 제목은 앱 설치 방법으로 정리했다. 설치 이벤트 구독/사용자 클릭 설치/취소/완료 반영과 manifest·서비스워커는 유지한다. 설치 안내 문서의 진입 경로도 갱신했다.
## 결과
빌드·설치/이용 안내 브라우저7개 통과. 홈 카드 없음, 이용 안내에서 수동 설치 설명/명시적 설치 요청·취소/설치 완료 및 standalone 안내 숨김을 확인했다.320/360/430px 큰 글씨와 안내/기록/뒤로가기 포함. 설치 이벤트/standalone은 모의 검증이며 실기기 설치 승인은 별도. AI 지원 수정/검증.
