# 카메라 방향 센서 사용 불가 사용자 보고

## 문제
2026-11-13 사용자가 실제 카메라에서 방향 표시가 잘 안 되며 방향 센서를 사용할 수 없다고 보고했다. 이전 갤럭시 울트라 사용 맥락은 있으나 이번 브라우저·정확한 문구·센서 진단·자세는 미확인이다. 권한 실패와 지원 입력 부족을 구분해야 한다.

## 원인 조사
현재 orientationToHeading은 webkitCompassHeading과 webkitCompassAccuracy를 모두 요구한다. 표준 alpha/beta/gamma/absolute만 받으면 정확도 정보를 확인할 수 없어 화살표를 숨긴다. beta 또는 gamma가 ±30°를 넘는 자세도 거부해 세워 든 카메라 사용을 지원하지 않는다. 이 제한은 기존 구현/문서에도 있으며 권한을 다시 허용하는 것만으로 해결되지 않는다. 실제 기기에서 어떤 입력을 받았는지는 아직 확인하지 않았다.
