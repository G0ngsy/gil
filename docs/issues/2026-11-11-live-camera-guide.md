# 실제 경로 카메라 방향 연결 (2026-11-11)

## 문제
카메라 미리보기와 실제 경로·GPS·방향 센서가 분리되어 있었다. 연결 후 검증에서 기존 카메라 시작 버튼의 절대 위치 스타일로 가로 넘침이 발생했고 직진 아이콘이 오른쪽을 향했다.

## 원인
시안 전용 카메라 컴포넌트와 수평 자세만 지원하는 방향 센서를 실제 안내에서 조합하지 않았다. 시안 버튼 스타일과 기본 화살표 아이콘 방향을 그대로 상속했다.

## 해결방법
실제 GPS 안내 중 선택적으로 카메라를 열고 별도 센서 시작 버튼으로 권한을 요청한다. 최신 실제 GPS Fix(정확도 포함)를 기존 진북 보정 및 경로 비교에 전달한다. 영상 재생·GPS 활성·유효 위치/방향 조건을 모두 만족할 때 안정화된 방향 표시를 사용한다. 불확실/오래됨/이탈 시 숨기고 영상 종료·안내 중지·탭 숨김 시 자원을 해제한다. 카메라만 닫으면 GPS 안내는 유지한다. 버튼은 일반 배치, 직진은 위쪽 아이콘으로 보정했다.

## 결과
빌드 및 단위 테스트 109개 통과. 카메라·센서·안내 배치 브라우저 테스트 28개 통과, 마지막 아이콘/CSS 조정 후 신규 통합 1개 재통과. API 응답·GPS·방향·영상은 이 테스트에서 모의 입력이다. 캡처도 모의 영상이며 실외 정확도 증거가 아니다.

지원 범위: 세로 화면, 화면을 위로 두고 바닥과 나란한 자세(기존 ±30° 제한), 신뢰 가능한 webkit 방위·오차 제공 환경. 세워 든 자세/오차 없는 Android 표준 이벤트는 화살표를 표시하지 않는다. 화면 오버레이이며 카메라 광축/바닥 고정 AR이 아니다. 실기기/실외/직립 자세 계산은 미확인·후속 작업이다. AI 지원으로 구현·검증했다.
