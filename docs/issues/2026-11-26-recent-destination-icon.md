# 최근 목적지 제목 아이콘

## 문제
최근 목적지 제목에 영역의 의미를 보조하는 아이콘이 없었다.
## 원인
공통 기록 컴포넌트의 제목이 글자만 표시했다.
## 해결방법
홈 요약과 기록 상세의 최근 목적지 제목 앞에 기존 clock 아이콘18px을 추가했다. 소나무색과7px 간격을 적용하고 아이콘은 장식으로 처리해 제목/버튼의 접근 가능한 이름을 유지했다.
## 결과
빌드·기록/검색 브라우저13개 통과.360/390/430px 모의 API 화면 검증과390px 시각 확인. 실기기 검증은 별도이며 저장/삭제 로직은 변경하지 않았다. AI 지원 수정. [화면](../portfolio/assets/2026-11-26-recent-destination-icon-390.png).
