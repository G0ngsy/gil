# 최근 검색·목적지 기기 저장

## 문제
검색과 선택한 목적지가 새로고침 후 사라졌고, 고정된 예시 목록이 최근 목적지라는 이름으로 표시됐다.

## 원인
브라우저 영구 저장이 없었고 화면의 React 상태와 예시 배열만 사용했다.

## 해결방법
버전이 있는 localStorage 키로 실제/예시 기록을 분리한다. 검색어와 목적지 ID·이름·주소만 각각 최대 10개 저장한다. 중복은 최신 순서로 올린다. 기존 고정 목록은 예시 목적지로 명칭을 변경한다. 개별 삭제와 확인 후 현재 모드의 전체 삭제를 제공한다. 저장 데이터 검증·손상된 JSON 처리·저장 및 삭제 실패 안내·다른 탭의 storage 이벤트 동기화를 추가한다. 실제 검색은 정상 응답 후 저장하며 최근 목적지를 다시 누르면 최신 검색 결과에서 사용자가 다시 선택하도록 한다. 목적지 좌표와 현재 위치·카메라 영상·경로는 저장하지 않는다.

## 결과
빌드·단위 21개·브라우저 33개 통과. 새로고침 유지·중복/최대 개수·개별/전체 삭제·손상된 저장값·저장 차단·실제/예시 분리·좌표 제외를 확인했다. 실제 TMAP 인증·실제 검색 품질은 키가 없어 검증하지 않았다. 사용자가 브라우저 데이터를 지우거나 비공개 모드를 끝내면 기록이 없어질 수 있다. 삭제가 브라우저 정책으로 실패하면 기존 저장값이 남을 수 있음을 알린다.
