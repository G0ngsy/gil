# 길 안내 헤더 높이 조정

## 문제
길 안내 화면의 72px 헤더가 지도 공간을 차지했다. 사용자는 높이를 줄이고 기능 없는 점 메뉴는 제거해 달라고 요청했다.

## 원인
일반 화면과 안내 화면이 같은 헤더 크기를 공유했다. 점 메뉴의 기능은 외형만으로 알기 어려웠다.

## 해결방법
안내 단계에만 guidance-header를 적용해 52px로 줄이고 절약한 20px를 지도 높이에 더했다. 뒤로/메뉴 누르기 영역은 44px 이상 유지한다. 메뉴에는 일시중지와 종료 기능이 실제 연결되어 있으므로 제거하지 않았다.

## 결과
빌드·관련 브라우저 6개 통과. 360/390/430px에서 헤더 52px와 메뉴 조작 영역 44px, 일시중지·재개, 종료 확인창 열기·취소, 지도 동작을 확인했다. GPS/지도 SDK는 모의 입력이며 실외 검증과 구분한다. AI 지원 구현.
