# 지도 경로 방향과 이동 핀 (2026-11-25)

## 문제
회전 구간에서 경로가 끊겨 보이고 진행 방향이 분명하지 않았다. 현재 위치도 이동 방향을 표시하는 핀 요청.

## 원인
API 선분을 각각 그려 동일 끝점의 경계가 겹쳤으며 경로 위 진행 표시가 없었다. 현재 위치는 원형 마커였다.

## 해결방법
끝점 거리5cm 미만인 연속 선분만 합쳐 그린다. 실제 떨어진 구간을 임의 연결하지 않는다. 남은 경로에35m 간격, 시작18m 이후 흰 꺾쇠를 최대40개 표시한다. 지난 경로는 회색을 유지한다. 위치 마커는 초기 핀, 이동 확인 후 방향형 핀으로 표시하며 라벨은 회전하지 않는다. 채택된 GPS 표본의 이동 방위만 쓰며 최소8m와 두 표본의 오차보다 큰 이동을 요구한다.15초 초과 공백·불확실·오래된 표본에서는 방향을 갱신하지 않는다. 정지 중 방향을 유지하고 새 경로 때 초기화한다. 휴대폰 시선/나침반/AR 또는 부드러운 위치 보간 기능이 아니다. 위치 이동 자체는 기존 GPS 갱신을 사용한다.
