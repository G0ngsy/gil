# 안내 중 남은 예상 시간 표시

## 문제
길 안내 시작 전에는 전체 시간과 거리를 함께 표시하지만 안내 중 접힌 시트에는 거리만 나왔다.

## 원인
RouteJourney의 안내 요약이 남은 거리만 렌더링하고 경로의 durationSeconds를 사용하지 않았다.

## 해결방법
경로의 전체 예상 시간에 남은 거리/전체 거리 비율(0~1)을 곱해 남은 예상 시간을 계산하고 분 단위 올림으로 약 N분을 표시한다. 기존 경로 거리/진행 데이터를 사용하며 실측 보행 속도나 도착 시각으로 표현하지 않는다. 안내 중에만 1초 간격으로 위치 신선도를 확인하고 해제 시 타이머를 정리한다. 위치가10초 이상 오래되거나 이탈/거절/안내 중지/도착 상태면 추정 시간을 숨긴다. 시간과 도보 거리를 같은 줄에 배치하고 큰 글씨는 줄바꿈한다. 마지막 위치/경로 끝 기준 표시는 유지한다.

## 결과
빌드·지도/바텀시트/지도 실패23개 통과. 예상3분→중지 시 숨김→재시작 복구→경로 절반에서2분→이탈/오래된 위치/도착 시 숨김을 모의 GPS/가상 시계로 검증했다. 중지/재시작 조건을 보강한 단독 테스트1개 최종 통과.320/390/430px 시트와360×640/200% 글씨에서 버튼/상세 접근을 확인했고390px 접힌 시트를 시각 검토했다. 모의 API/GPS/지도 SDK 검증이며 실제 사용자의 소요 시간 예측 정확도와 실외 보행 성능은 미확인이다. AI 지원 구현/검증.
