# 검색창 아래 홈 카드 배치

## 문제
홈의 검색창 아래에 배경용 큰 여백이 있어 안내 복귀/현재 위치 카드가 멀리 떨어졌다. 현재 위치 카드에도 오차·확인 시각·큰 버튼이 있어 참고 이미지보다 복잡했다.

## 원인
기존 두 줄 제목과 처마 하단 장식을 위해 hero에 최소 높이와 135~145px 하단 패딩이 있었다. 위치 카드를 경로 설정 화면과 같은 상세 형태로 공유했다.

## 해결방법
제목을 한 줄로 가운데 배치하고 산수·한옥 배경 위에 겹쳤다. 배경을 옅게 처리해 제목과 검색 가독성을 유지하고 검색 하단 패딩/최소 높이를 줄였다. 안내가 있으면 검색→안내 복귀 카드→현재 위치, 없으면 검색→현재 위치 순으로 바로 이어진다. 홈 위치 카드는 위치명과 44px 위치 확인 아이콘 버튼으로 축소했다. 오차·확인 시각은 홈에서 숨기고 경로 설정에서는 유지한다. 주소 조회 실패/권한 오류/주소 재시도는 계속 표시하며 위치 권한을 자동 요청하지 않는다.

## 결과
빌드·관련 브라우저20개 통과, 간격 검증 추가 후 홈/안내 세션12개 재통과. 360/390/430px에서 검색창과 다음 카드, 안내 카드와 위치 카드 간격24px 이하, 기본 위치 카드100px 이하, 가로 넘침 없음 확인. 주소 조회/재확인과 홈 안내 유지 동작은 모의 API/GPS로 검증했다. 실제 배포 확인은 후속 기록 참조. AI 지원 구현·검증.
