# 지도 카메라 전환 버튼 (2026-11-25)

## 문제
시트를 접으면 카메라 진입 버튼이 숨겨져 전환을 위해 상세를 펼쳐야 했다.

## 원인
카메라 실행 버튼이 상세 패널 안에 배치되어 있었다.

## 해결방법
지도가 준비되면 현재 위치 버튼 위에 녹색 '카메라로 보기' 버튼을 배치한다. 기존 실행 버튼만 portal로 이동하고 카메라 세션·권한 요청·영상 해제·뒤로가기 및 초점 복귀는 기존 컴포넌트에서 유지한다. 지도 실패/준비 전에는 상세 패널의 기존 버튼을 유지한다. 사용자가 누르기 전에는 권한을 요청하지 않는다.

## 결과
빌드 통과. 관련 브라우저 검증·배포 결과는 아래 추가한다. AI 지원 구현/검증/문서. 모의 SDK/API/GPS 검증이며 실기기 조작 확인은 별도다.

검증 중 발견: 카메라 닫기 직후 본문 inert 해제 전에 초점을 요청해 복귀 초점이 누락됐다. 다음 animation frame에서 버튼에 초점을 돌리도록 수정하고 가상 시계도 진행해 확인한다.

화면 캡처에서 기존 camera-launch의 absolute 위치 규칙이 남아 버튼이 세로로 줄바꿈됨을 발견했다. 지도 버튼은 static/inset 초기화·nowrap을 적용하고 가로폭/높이 검증을 추가했다.

검증 완료: 빌드, 관련18개 및 초점 수정 후9개 통과. 최종 스타일 보완 후 직접 열기/뒤로가기/버튼 치수1개 통과. 모의 지도 캡처를 시각 검토했다.
