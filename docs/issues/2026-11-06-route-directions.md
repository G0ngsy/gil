# 전체 도보 안내 목록

## 문제
경로를 받아도 첫 번째 안내만 표시되어 이후 이동 순서를 확인할 수 없었다. 지도 로딩에 실패하면 거리·시간 외의 정보를 확인하기 어려웠다.

## 원인
경로 응답의 steps 배열에서 첫 번째 description만 렌더링했다.

## 해결방법
접고 펼칠 수 있는 전체 안내 목록에 제공된 문구를 순서대로 표시한다. 빈 문구는 제외하고 안내가 없으면 명시적으로 알린다. 현재 위치 기반 자동 안내가 아님을 표시한다. 긴 문구는 줄바꿈하고 목록의 내부 스크롤 대신 기존 화면 스크롤을 사용한다.

## 결과
빌드와 단위 테스트 18개 통과. 브라우저 테스트 12개 통과. docs/validation-2026-11-06-directions.md에 검증 범위를 기록했다. 실제 TMAP 인증·경로 품질 확인은 API 키 발급 이후로 보류한다.
