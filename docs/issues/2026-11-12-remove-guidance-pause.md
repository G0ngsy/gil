# 수동 일시중지 제거와 종료 버튼 이동

## 문제
사용자가 안내 일시중지 흐름을 제거하고 안내 종료를 남은 거리 옆에 작게 배치하도록 요청했다.

## 원인
일시중지/종료가 자세히 보기 안에 있어 조작이 숨겨지고 불필요한 수동 중지 흐름이 추가됐다.

## 해결방법
수동 일시중지 버튼과 콜백을 제거했다. 남은 거리 행 오른쪽에 작은 안내 종료 버튼을 배치하되 최소 44px 누르기 높이를 유지했다. 자세히 보기의 종료 중복을 제거했다. 종료 확인창, X 홈 복귀/GPS 안내 유지 동작은 보존했다. 탭 숨김·GPS 오류의 자동 중지 처리는 유지하고 복구 버튼을 ‘위치 안내 다시 시작’으로 구분했다. 홈/지도 상태 문구에서도 수동 일시중지 표현을 제거했다.

## 결과
빌드·관련 브라우저 30개 통과. 360/390/430px 종료 버튼 화면 내 표시, 수동 일시중지 없음, 종료 확인/취소/확정, 홈 복귀, 자동 위치 중단 후 복구를 모의 GPS로 검증했다. 실제 배포 확인은 후속 기록 참조. 실외 위치 정확도는 미검증. AI 지원 구현.
