# 승인된 전통 구분선 적용

## 문제
사용자가 생성된 비교 이미지의 홈 마름모 구분선과 도착 연꽃 구분선을 그대로 적용하도록 요청했다. 기존 도착 연꽃은 두 색의 굵은 문양으로 예시의 가는 단색 장식과 달랐다.

## 원인
실제 홈에는 장식 구분선이 없었고 기존 Motif 연꽃은 아이콘용 디자인이었다. 최초 검증은 이전 연꽃 클래스가 남아 있을 것으로 예상해 실패했다.

## 해결방법
독립적인 OrnamentalDivider SVG 컴포넌트로 마름모 3개/연꽃과 양쪽 선을 만든다. 황토색 토큰과 가는 선을 사용하며 장식은 aria-hidden, 포인터 비활성으로 기능 아이콘과 분리한다. 실제 홈의 현재 위치/최근 목적지 사이, 시안 도착의 완료 표시 위, 실제 경로 도착 상태에 적용했다. 이전 검사도 승인된 새 연꽃으로 갱신했다. 데이터·거리·시간·도착 판정은 변경하지 않았다.

## 결과
빌드 통과. 최초 관련 브라우저 21개 중 이전 연꽃 검사 1개 실패 → 검사 갱신 및 배치 검사를 추가해 24개 모두 통과. 360/390/430px의 구분선 위치·버튼 노출·가로 넘침, 검색 전환·모의 GPS 도착을 확인했다. 실제 API/GPS는 이번 검증에서 모의 응답·입력이며 실외 정확도 확인은 아니다. 390px 실제 렌더링 캡처를 portfolio/assets에 보관했다. AI 지원으로 SVG·CSS·검증을 작성했고 이미지 전체를 UI에 붙이지 않았다.
