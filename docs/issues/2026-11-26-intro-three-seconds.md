# 기본 문 스플래시를 홈 전환 포함 3초로 조정

## 문제
기존 기본 문 연출은4.55초에 이미지 준비 대기 최대1.5초가 더해져 사용자가 원하는3초보다 길었다.

## 원인
이미지 decode 완료 후 타이머를 시작했고 로고 유지/퇴장/홈 전환 구간도 길었다.

## 해결방법
효과 시작 시점부터3000ms 종료를 예약한다. 이미지 준비는 병렬로 진행하고 종료를 늦추지 않는다. 0.3초 문 열림 시작→1.4초 로고 등장→2초 로고 퇴장→2.3초 홈 줌인/페이드→3초 홈 조작 가능. 문 열림1.1초 유지, 로고 페이드0.25초, 마지막 전환0.7초. 스킵/세션 기록/타이머 정리 유지, 동작 줄이기는 이미지 대기 없이 즉시 종료한다.

## 결과
빌드 통과. 기본 문 브라우저10개 최종 통과(360/390/430/1280px, 스킵/세션/동작 줄이기/이미지 실패·저장 차단, 이미지 decode 무기한 지연 포함3000ms 경계). 별도 개선안 브라우저4개도 통과했다. 실기기 프레임/실제 네트워크 시간은 미측정. 타이머는 브라우저 메인 스레드 상태에 따라 실제 실행이 지연될 수 있으며3초는 앱이 예약하는 전체 연출 길이다. 이미지가 늦으면 일부 배경/로고가 늦게 표시될 수 있지만 홈 진입을 기다리게 하지 않는다.

초기3000ms 경계 테스트에서 Playwright 시계가 실제 시간과 함께 진행돼2999ms 확인 전에 종료됐다. 페이지 진입 전에 시계를 정지해 테스트 시간만 흐르게 수정했다. 제품 타이머를 늘려 맞추지 않았다. AI 지원 구현/검증.
