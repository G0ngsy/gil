# 사용자 관점 화면 정리와 선택·재확인 장식

## 문제
사용자가 승인한 선택 카드 창살·구름무늬를 적용하고, 실제 앱처럼 테스트하도록 TMAP 연결 상태/좌표 전달/개발 설명을 화면에서 제거하도록 요청했다.

## 원인
초기 연동 확인용 문구와 진단 도구가 실제 기능 화면에도 남아 있었다. 선택한 장소를 확인할 장식은 없었고 재확인 구름은 두 색의 굵은 문양이었다. 카드 선택 즉시 경로 확인으로 이동하므로 선택 디자인을 보여주기 위해 흐름을 바꿀 필요는 없었다.

## 해결방법
선택한 목적지와 검색 결과로 돌아온 뒤 해당 카드에만 녹색 테두리·체크·작은 황토색 창살을 표시한다. SelectionCorner는 순수 장식이며 결과 버튼은 aria-pressed로 선택 상태를 전달한다. 단색 가는 구름 SVG를 시안 재확인과 실제 카메라 방향 미확인 상태에 재사용한다.

실제 홈/경로의 좌표 전달 설명, TMAP 연결 상태 푸터, 개발 설정 안내를 제거했다. 카메라 시험 문구를 사용자 조작 안내로 바꾸고 공급자 인증/설정 오류는 사용자용 재시도 문구로 변환한다. 개발 소개 패널과 센서 진단은 preview=1 검토 모드에만 렌더링한다. 권한 요청·오차·사용 불가·안전 안내, 검색 범위·직선 거리, 지도 출처 표시는 유지했다. API 키/권한/검색·위치 처리 및 저장 방식은 바꾸지 않았다.

## 결과
최종 빌드 및 기본 테스트 109개 통과. 전체 브라우저 테스트 113개 통과. 선택/복귀·문구 제거·미선택 카드 장식 없음·360/390/430px 배치·일반 모드 진단 숨김·검토 모드 진단/복사·위치/검색/기록/카메라/인트로를 검증했다. 첫 전체 실행은 이전 준비 문구 검사 1개, 소스 수정 시점과 겹친 인트로 시간 검사 1개가 실패했다. 문구 검사를 갱신하고 최종 소스를 고정한 재실행은 모두 통과했다.

브라우저 검증의 API/GPS/카메라/방위는 모의 입력 또는 가상 장치다. 새 실외 정확도 검증을 뜻하지 않는다. 캡처 user-search는 모의 검색, user-recheck는 예시 거리·시간을 사용하는 명시적 시안이다. 사용자가 승인한 이미지에 따른 AI 지원 구현이다. 배포 결과는 deployment.md에 별도 기록한다.
