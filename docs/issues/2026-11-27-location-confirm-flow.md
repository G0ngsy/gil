# GPS 먼저 확인하고 사진 단서를 비교하는 위치 확인 흐름

구현/로컬 검증:2026-11-26. 문서/커밋 마무리:2026-11-27.

## 문제
홈의 위치 조회와 사진 확인이 별도 기능처럼 보여 순서가 불명확했다. 사용자는 GPS 지도/주소를 먼저 보고 맞으면 검색, 헷갈리면 재조회 또는 사진 비교하는 화면과 푸시 전환을 요청했다.

## 원인
위치 카드는 즉시 GPS만 조회하고 사진 기능은 별도 홈 버튼/결과 화면으로 끝났다. 두 정보를 함께 보여줄 상태·지도·확인 단계가 없었다.

## 해결방법
홈 위치 카드→내 위치 확인 화면에서 GPS/주소·파란 점/오차 반경을 표시한다. 사진은 보조 버튼으로 진입하고 확인한 장소는 초록 핀/이름/주소로 비교한다. photoReference와 실제 GPS를 분리해 사진 좌표를 Fix로 만들지 않는다. GPS 실패 시 사진 장소만 표시하고 시작은 비활성화한다. 다시 확인은 GPS만 갱신하고 단서는 유지한다. 이 위치에서 길찾기는 홈 검색창에 초점을 두며,120초 지난 위치는 재조회 후 확인하게 한다. 기존 목적지 직접 검색은 유지한다.

홈↔위치↔사진에0.3초 양방향 푸시를 적용했다. 사진 완료는 비교 지도로 복귀하며 홈에서 위치 카드를 다시 열면 과거 단서를 초기화한다. 지도/마커/ResizeObserver를 정리하고 진행 중 안내는 보존한다. 새 코드에 역할/수명/좌표 분리의 한국어 주석을 추가했다. [전체 화면 전환](../screen-transitions.md).

기존 안내 테스트1개는 위치 조회 후 바로 홈에서 입력하던 옛 흐름 때문에 실패했다. 새 확인 버튼을 거치는 사용자 흐름에 맞춘 후 관련50개를 재통과했다. 사진 테스트도 독립 홈 진입 대신 GPS→사진→비교 지도에 맞췄다.

문서 저장 명령은 PowerShell 문자열의 문장부호 해석 문제로 실행되지 않아 패치로 저장했다. 원격 조회는 자동 승인 검토 사용량 제한으로 실행되지 않았고 사용자 재개 후 다시 확인한다. 이 실패는 안전성 거절이 아니다.
