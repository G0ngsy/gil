# 안내 화면 닫기와 안내 종료 분리

## 문제
지도·카메라·방향 재확인 화면의 X가 안내 종료 확인창을 열어 화면 닫기와 종료가 같은 동작이었다.

## 원인
상단 X와 하단 안내 종료 버튼이 같은 종료 상태를 변경했다. 화면과 안내 상태가 분리되어 있지 않았다.

## 해결방법
X는 홈으로 이동하고 안내 목적지와 마지막 화면을 별도로 보관한다. 홈에 진행 중인 안내 카드와 복귀·종료 버튼을 표시한다. 명시적 종료 확인과 도착 시에만 안내 상태를 해제한다. 다른 목적지를 살펴봐도 기존 안내 목적지를 유지한다. 화면 전환 시 재확인 시안 타이머를 취소해 닫은 화면이 다시 열리지 않게 한다.

## 결과
실제 백그라운드 GPS·음성 안내가 아닌 시안의 안내 상태 유지 구현이다. 페이지 새로고침·탭 닫기까지 상태를 보존하지는 않는다. 검증 결과는 작업 검증 문서에 기록한다.
