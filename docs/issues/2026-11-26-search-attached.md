# 검색창과 최근 검색 목록 연결

## 문제
최근 검색어가 검색창 아래 별도 카드로 떨어져 보여 사용자에게 두 영역이 분리된 느낌을 줬다. 입력창 자체 포커스 외곽선도 겹쳤다.

## 원인
목록 top에8px 간격이 있고 양쪽 모두 둥근 테두리와 그림자를 가졌으며 form/input 각각의 포커스 표시가 중복됐다.

## 해결방법
목록이 열렸을 때 검색창은 위쪽 모서리, 목록은 아래쪽 모서리만 둥글게 하고 동일한 배경/녹색 외곽 테두리로 연결했다. 목록 간격을 없애고 중복 포커스 외곽선 대신 검색 영역 테두리로 포커스를 표시한다. 목록 내부 버튼의 키보드 포커스 표시는 유지한다. 기존 선택/삭제/Escape/바깥 클릭 동작과 겹쳐 펼치는 배치를 유지한다.

## 결과
빌드 및 검색 경험 브라우저8개 통과.360/390/430px 모의 API 화면을 확인하고390px 캡처를 검토했다. [화면](../portfolio/assets/2026-11-26-search-attached-390.png). 실제 모바일 키보드/기기 검증은 미확인. AI 지원으로 CSS 수정/검증했으며 실제 검색 서버와 저장 동작은 변경하지 않았다.
