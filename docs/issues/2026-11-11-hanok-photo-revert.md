# 한옥 사진 적용 되돌림

## 문제
사진이 UI에 붙여진 느낌으로 기존 한지색·벡터 일러스트 디자인과 어울리지 않는다는 사용자 피드백을 받았다.

## 원인
참고 이미지를 기존 일러스트의 형태·분위기에 반영하기보다 원본 사진을 직접 배치했다. 페이드만으로 사진과 기존 장식의 표현 방식 차이가 해소되지 않았다.

## 해결방법
실제 홈의 Hanok 벡터와 스타일을 사진 적용 직전 0bfa019로 복원하고 사진 전용 배포 자산을 제거했다. 검색 범위 상단 배치와 기능은 유지한다. 과거 사진 캡처는 이력으로만 보존한다.

## 결과
빌드 통과. 배포에서 360/390/430px 일러스트 존재·사진 요청 없음·검색 범위 상단 유지 확인. 포트폴리오 기록에 결과를 추가했다. 이후 참고 이미지 반영에서도 기존 표현 방식과 일관성을 우선한다.
