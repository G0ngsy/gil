# 홈 방향 센서 진단 (2026-11-26)

## 문제
설치형 앱에서 방향 센서 진단을 시작할 화면이 없었다.

## 원인
기존 진단 UI는 일반 화면에 연결되지 않았고 실험 센서 기능은 GPS 안내에 의존했다.

## 해결방법
홈 하단 방향 센서 진단 버튼과 별도 화면을 추가했다. GPS/카메라 없이 센서를 시작·중지하고 상대/절대 이벤트를 종류별로 기록한다. 원본 각도·오차·이벤트 수·설치 모드와 브라우저 정보를 수동 확인/복사한다. 자동 저장·전송하지 않는다. 권한 요청 취소·화면 숨김/이탈/뒤로가기 시 해제하고 늦게 허용된 요청도 무시한다.10초 미수신 안내를 제공한다. 원본 값 수신을 정확한 방위/AR 성공으로 판단하지 않는다.

## 결과
빌드·브라우저3개 통과(모의 센서): GPS 요청0·이벤트 종류 구분·결과 복사·중지 뒤 수신 해제·화면 복귀 자동 시작 없음·거절/늦은 허용 취소·가로 넘침. 초기 테스트의 가상 권한 거부·브라우저 초기 이벤트 수 문제를 명시적 권한 응답과 중지 시점 기준 비교로 보완했다. 실제 갤럭시 결과 수집은 다음 단계. AI 지원 구현·검증·문서. 문서/푸시 직전 자동 승인 검토의 사용량 제한으로 호출이 미실행됐으며 사용자 재개 후 이어서 수행한다.

## 사용자 확인 순서
홈 하단 방향 센서 진단→센서 시작→천천히 좌우로 회전→센서 중지→센서 진단 펼침→진단 결과 확인→진단 결과 복사. 설치 앱과 삼성 인터넷/Chrome에서 비교한다.

통합·운영 확인: 원격1972f83의 홈/검색 변경을 확인해 문서 양쪽 기록과 최신 화면을 보존했다. 통합 빌드·진단/검색 브라우저11개 통과. 제품65046af Vercel success, 운영 주소의 진단3개 통과(가상 센서/권한). 실제 갤럭시에서 결과를 수집하는 단계가 남아 있다. 후속 커밋은 결과 기록만 수정.
