# X로 홈 이동과 안내 세션 유지

## 문제
기존 실제 안내는 화면 단계와 검색 경로 상태를 공유했다. 뒤로/화면 이동, 현재 위치 재확인, 다른 장소 검색이 GPS를 중지하거나 경로를 지웠다. 일시중지 후 재개도 진행값을 초기화했다. 사용자는 X로 홈에 돌아가도 안내 유지, 홈 복귀 카드, 별도 일시중지/종료 흐름을 확정했다.

## 원인
선택한 검색 결과와 안내 중 목적지/출발/경로를 같은 상태로 관리하고 범용 취소 함수에서 위치 추적을 함께 중지했다. 시작과 재개 동작도 같았다.

## 해결방법
진행 중인 안내 세션에 목적지·출발지·경로를 별도로 보관하고 GPS는 그 세션 경로에만 적용한다. X와 안내 화면의 뒤로 가기는 홈으로 이동하며 GPS를 유지한다. 홈에 목적지/진행 상태/남은 거리와 ‘안내로 돌아가기’를 표시한다. 다른 장소 탐색과 위치 재확인으로 기존 세션을 지우지 않는다. 새 경로 시작은 기존 안내를 교체할지 확인한 뒤 한 번에 변경한다. 일시중지는 자세히 보기에 두고 화면과 진행값을 유지한다. 재개는 새 GPS 수신만 시작한다. 종료는 확인창 확정 후 추적·경로·복귀 카드를 지운다. 홈에 머물 때도 도착 판정은 진행하고, 카메라 중 X 이동은 영상/방향 센서를 해제한다.

탭 숨김·화면 잠금·다른 앱 이동 시 기존 GPS 중지 규칙은 유지한다. 자동 재시작이나 백그라운드 추적, 새로고침 후 세션 복원을 구현한 것으로 표현하지 않는다. 홈 카드도 중지/도착 상태를 구분한다.

## 실제 SDK 확인에서 발견한 추가 문제
