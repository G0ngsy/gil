# 홈 현재 위치 버튼의 가시적 설명

## 문제
사용자가 현재 위치의 아이콘만 보고 어떤 버튼을 눌러야 하는지 알기 어렵다고 지적했다.

## 원인
홈의 위치 버튼은 아이콘과 aria-label/title만 제공했다. 마우스를 올리지 않는 터치 사용자는 툴팁을 볼 수 없었다.

## 해결방법
아이콘 옆에 항상 보이는 텍스트를 추가하고 옅은 녹색 배경/테두리로 버튼 영역을 드러냈다. 처음은 현재 위치 확인, 수신 중은 확인 중…, 확인 후는 다시 확인이다. 전체 의미를 전달하는 기존 aria-label·확인 중 비활성화·위치 재확인 함수와44px 최소 높이를 유지했다. 다른 화면의 기존 글자 버튼은 변경하지 않았다.

## 결과
빌드 및 기존 홈/위치 검색/위치 오차 개선 검사14개 통과. 360/390/430px 가로 넘침·현재 위치 버튼 노출·검색/위치 재확인·주소 유지 흐름을 확인했다. API/GPS는 모의 입력이며 실외 측정은 아니다. 390px 캡처를 보관했고 AI 지원으로 수정했다.
