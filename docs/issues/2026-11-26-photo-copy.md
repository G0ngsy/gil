# 사진 화면 문구 일반화

## 문제
사용자는 간판에 한정된 촬영 버튼과 제목 대신 현재 있는 주변을 보여준다는 표현을 원했다.
## 원인
초기 문구가 ‘주변 간판’, ‘간판 촬영’, ‘간판과 지점명’ 중심으로 작성됐다.
## 해결방법
제목을 ‘지금 계신 곳을 보여 주세요’, 버튼을 ‘사진 촬영’으로 바꿨다. 설명은 ‘안전한 곳에 멈춰 주변 건물의 이름이나 글자가 보이게 촬영해 주세요’로 정리했다. 단순 풍경에서 정밀 위치를 추정한다고 오해하지 않도록 글자 단서는 유지한다. 미리보기 대체 텍스트/파일 입력 이름/읽기 상태도 사진 표현으로 맞췄다. OCR과 검색 동작은 변경하지 않았다.
## 결과
빌드와 사진/기존 안내 브라우저19개 통과.360/390/430px 흐름·푸시/복귀·실제 OCR 합성 입력·취소/실패·큰 글씨·기존 GPS/목적지 유지 검증. 모의 API/GPS와 실제 엔진을 구분하며 실기기 촬영/현장 사진 정확도는 미확인. AI 지원 문구/코드·검증.
