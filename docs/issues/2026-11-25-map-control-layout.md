# 지도 조작 버튼 정리 (2026-11-25)

## 문제
카메라 버튼을 현재 위치 버튼 아래 상태 문구 위치로 옮기고, 시트 토글 문구를 점 표시로 줄여 달라는 요청.

## 원인
기존은 카메라→현재 위치→상태 문구 순서였고 토글에 설명 문구와 손잡이를 함께 표시했다.

## 해결방법
현재 위치→카메라 순서로 배치하고 상태 문구는 시각 표시에서 제거했다. 스크린리더용 상태는 유지한다. 토글은 점3개로 표시하며 aria-label/expanded/controls 및44px 터치 영역을 유지한다. 지도 추적 상태 검증은 화면 문구 대신 data-following으로 확인한다.

## 결과
빌드 통과. 브라우저·배포 결과는 아래 기록한다. 모의 SDK/API/GPS 검증, 실기기 확인은 별도. AI 지원 구현·검증·문서.

검증: 빌드·관련 브라우저14개 통과. 320/390/430px, 큰 글씨, 접기/펼치기·카메라 전환/초점·지도 추적 상태 확인. 모의 지도 캡처(assets/2026-11-25-map-control-layout-390.png) 시각 검토.

캡처 보완: sr-only 상태 문구가 다른 스타일에 의해 표시되어 해당 문구 DOM을 제거했다. 지도 추적 상태는 내부 data-following과 기존 GPS 안내로 확인한다. 앞의 스크린리더 문구 유지 설명은 최종 구현에서 대체됐다.

최종 확인: 상태 문구 완전 제거 후 빌드·전환1개 통과. 제품4e5923f Vercel success, 운영 주소에서도 버튼 위치·점 토글·상태 문구 없음·카메라 전환/복귀1개 통과(모의 SDK/API/GPS). 실기기 확인 별도. 후속 커밋은 기록만 변경.
