# 홈 제목 위 여백 축소

## 문제
사용자가 어디로 걸어갈까요? 위쪽 빈 공간이 커서 제목을 조금 위로 올리도록 요청했다.

## 원인
실제 홈 hero의 상단 padding이76px로 설정되어 있었다.

## 해결방법
상단 padding만48px로 줄여 제목과 검색 영역을28px 위로 당겼다. 글자 크기·가운데 정렬·배경·기능은 유지했다.

## 결과
빌드와 기존 모바일360/390/430px 홈 배치·검색 전환 검사3개 통과. 현재 위치 버튼 노출·검색창/위치 카드 간격·가로 넘침을 확인했고390px 캡처를 보관했다. API는 모의 응답이며 실기기 확인은 별도다. AI 지원 수정.
