# 배포 화면과 디자인 검토 화면 분리

## 문제
배포된 PC 화면에서 휴대폰 목업 테두리·고정 시간·양쪽 설명·시안 메뉴까지 보여 앱이 아닌 디자인 발표 화면처럼 보였다.

## 원인
디자인 시안 제작 단계의 studio 레이아웃을 배포 기본 화면으로 그대로 사용했다. 기능 연결과 배포 준비 과정에서 실제 사용자용 외곽 화면 전환이 누락됐다.

## 해결방법
기본은 앱 레이아웃으로 표시한다. 휴대폰 목업·가짜 상태 표시·하단 제스처 막대·설명판·검토 메뉴를 숨기고 실제 화면 높이와 safe-area에 맞춘다. 넓은 화면에서는 최대 480px 앱 영역을 중앙에 표시한다. 검토 도구는 ?preview=1일 때만 제공한다. 기본 화면에서도 가상 데이터가 실제 안내로 보이지 않게 예시 경로 표시를 유지한다. 실제 검색 모드에도 같은 외곽 규칙을 적용한다.

## 결과
빌드·브라우저 테스트 30개 통과 후 같은 주소에 재배포했고 실제 배포 PC/모바일 크기에서 앱 레이아웃과 API HTTP200을 확인했다. 실제 경로·AR 개발 완료를 의미하지 않는다.
