# 기본 문 스플래시 복원과 문 부분 개선

## 문제
사용자가 기본 스플래시를 기존 문 열림 연출로 돌리고, 개선안 중 문 열리는 부분만 적용하도록 요청했다.

## 원인
App 기본 분기가 매듭이었고 기존 문은 intro=1 비교 주소에서만 실행됐다. 기존 문 이미지는 가로 자산을 세로로 늘려 비율이 변했다.

## 해결방법
기본 App 분기를 Intro로 복원했다. Intro의 배경·중앙 로고 등장/퇴장·홈 확대/페이드·기존 세션 노출 정책은 유지한다. 문만 개선안 Door 컴포넌트를 공유해 밝은 갈색·고정 굵기 창살·23px 원형 문고리·1.1초 열림으로 바꿨다. 더 이상 쓰지 않는 문 이미지의 decode 대기는 제거하고 배경/로고 준비는 유지했다. 매듭/세 걸음은 splash=knots/steps 비교 주소에서만 실행하며 독립 컴포넌트의 splashSeen 기능은 유지한다. intro=refined 전체3초 개선안도 별도로 보존했다.

## 결과
빌드 및 관련 브라우저33개 통과. 360/390/430/1280px 문 비율·1.1초 transition, 기존 로고·배경·홈, 기본/비교 주소, 세션 재진입, 동작 줄이기, 저장 차단, 대체안 독립 컴포넌트 정책을 확인했다. 이번 기본 문 연출의 전체 타이머는 기존4.55초이며 이미지 준비·페이지 로딩은 별도이므로 총3초로 설명하지 않는다. 사용자 지시에 따라 문 부분만 바꾼 결과다. API/GPS/실기기 성능 검증 범위가 아니며 AI 지원 구현이다.
