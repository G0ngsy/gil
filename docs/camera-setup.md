# 카메라 경로 안내

## 현재 실제 안내 방식 — 2026-11-13

1. 실제 장소 검색 → 현재 위치/도보 경로 → 길 안내 시작.
2. 카메라 안내를 눌러 카메라 권한을 허용한다. 방향 센서 권한이나 자세 설정은 요청하지 않는다.
3. 지도와 동일한 경로/GPS 안내를 카메라 영상 위 고정 카드로 본다. 직진/좌우회전/유턴 아이콘과 안내점 거리를 표시하며 제공사 경로에서 확인할 수 없는 방향은 만들지 않는다.
4. 이탈·부정확/오래된 위치·수신 중단에는 행동 화살표 대신 상태 문구를 표시한다. 도착 때 GPS는 종료하지만 카메라 카드에 도착을 표시한다.
5. 카메라 끄기/지도 보기/X는 영상 트랙을 해제한다. GPS 안내 세션은 유지한다. 안내 종료·탭 숨김·페이지 이탈 때 자원을 해제하며 자동 재시작하지 않는다.

이 화살표는 **경로상 다음 행동**이며 현재 휴대폰/몸이 바라보는 방향이 아니다. 사용자가 반대 방향을 보고 정지한 상태는 GPS만으로 알 수 없다. 바닥/도로에 고정하는 AR이나 카메라 영상 분석은 제공하지 않는다. 카메라 영상은 저장/전송하지 않는다. 카메라는 HTTPS 또는 같은 기기 localhost에서 사용한다.

기존 검토 전용 `/?preview=1&mode=simulation`의 방위 센서 테스트는 별개로 유지한다. 일반 실제 카메라 화면에는 센서 시작·모의 좌표·센서 진단 도구가 없다. 예전 시안 카메라 화면은 실제 경로 안내로 취급하지 않는다.

## 모의 실행과 재생

프로젝트 루트에서 `node scripts/demo-camera-route.mjs`를 실행하면 휴대폰 크기 Chrome 창에서 모의 이동을 시연하고 영상을 저장한다. 창 없이 녹화할 때는 `--headless`를 붙인다. 설치된 Chrome과 Playwright 녹화 도구가 필요하며 녹화 도구는 `npx playwright install ffmpeg`로 준비한다.

이 시연은 **브라우저 모바일 에뮬레이션**이며 Android OS 에뮬레이터/실기기 검증이 아니다. 카메라 영상·위치·경로 API를 모두 모의하며 화면에 이를 표시한다. 실제 카메라/사용자 GPS를 사용하거나 TMAP을 호출하지 않는다. 제품에 모의 입력을 추가하지 않고 자동화 실행에서만 주입한다.
