# 현재 위치 주소·주변 검색 검증

## 변경 범위

기준 5fbc65f. 서버 주소 변환/중심 검색 요청, 클라이언트 POST 전송, 홈 위치 표시와 검색 범위 선택, 검색 기준 표본을 추가했다. 상세 과정은 docs/issues/2026-11-11-location-search.md를 따른다.

## 로컬 검증

- npm test: 단위 109개 통과. WGS84/A10/확장 없음 요청, 거리순 R/10km 중심 요청·서버 범위 필터/정렬, 잘못된 좌표 거부, 주소 없음 처리 포함.
- npm run build: 타입 검사와 Vite 빌드 통과.
- 최초 전체 브라우저 88개 통과 후 전국 선택/오래된 위치 검사 2개를 추가했다.
- 위치 검색 7개 별도 실행에서 6개 통과/좌표 부동소수점 엄격 비교 1개 실패. 정밀도 비교로 수정했다.
- 수정 후 최종 전체 브라우저 90개 통과. 부분 결과 합산이 아닌 전체 재실행 결과다.
- 현재 위치 주소/오차/확인 시각, POST 본문 중심 좌표(브라우저 URL에 없음), 전국/주변 라벨, 주소 실패와 재시도, 늦은 주소 무시, 빈 결과 전국 재검색, 사용자 전국 선택, 2분 경과 재수신을 확인했다.
- 위치/주소 localStorage 미기록 확인. 기존 GPS/센서/카메라/기록/360·390·430px 회귀 통과.
- 자동화는 모의 API/GPS를 사용했다. 실제 휴대폰 위치와 주소/검색 품질의 증거는 아니다.
- React 점검: 주소 요청 abort/해제, 이전 요청 응답 무시, 검색 당시 기준 스냅샷, 명시적 버튼 권한 요청, 기본/검토 모드 분리 유지.

실제 배포 확인은 아래에 추가한다. 자료 생성·공식 API 확인·구현/검증·문서화는 사용자 지시하의 AI 지원이며 실외 정확도 성과를 측정하지 않았다.

## 초기 설정 확인 경합 수정

첫 원격 브라우저 검증은 주소 요청이 발생하지 않아 30초 대기 후 실패했다. 설정 확인 중일 때 주소 요청을 건너뛰는 조건을 수정하고 config 응답을 보류하는 회귀를 추가했다. 재빌드 및 최종 전체 브라우저 91개 통과. 배포 서버의 실제 주소 API는 공공 좌표에서 HTTP200 및 서울특별시 중구 명동 주소를 반환했다. 수정 후 원격 UI 재확인은 재배포 후 기록한다.
