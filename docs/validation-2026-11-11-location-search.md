## 초기 설정 확인 경합 수정

첫 원격 브라우저 검증은 주소 요청이 발생하지 않아 30초 대기 후 실패했다. 설정 확인 중일 때 주소 요청을 건너뛰는 조건을 수정하고 config 응답을 보류하는 회귀를 추가했다. 재빌드 및 최종 전체 브라우저 91개 통과. 배포 서버의 실제 주소 API는 공공 좌표에서 HTTP200 및 서울특별시 중구 명동 주소를 반환했다. 수정 후 원격 UI 재확인은 재배포 후 기록한다.
