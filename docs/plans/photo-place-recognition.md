# 사진으로 주변 장소 확인 구현 계획

확정: 2026-11-26. 사용자 선택: 주변 장소 확인까지만 구현. 기능별 한국어 주석, 홈↔사진 화면 푸시 전환 포함.

## 사용자 흐름
홈 현재 위치 카드 아래 ‘사진으로 주변 장소 확인’→오른쪽에서 들어오는 0.3초 화면 전환→촬영/사진 선택→미리보기→글자 읽기→읽은 줄 선택/검색어 수정→장소 찾기→후보 이름·지점·주소 비교→사진에서 찾은 장소→확인 완료로 홈 복귀. 뒤로가기는 반대 전환, 동작 줄이기는 생략한다.

## 입력과 OCR
JPEG/PNG/WebP 최대10MB, 긴 변2048px 이하로 비율 유지 축소. 자르기 편집은 후속. 사용자가 글자 읽기를 눌러야 한국어/영어 OCR을 실행한다. Tesseract.js와 언어 자료는 버전 고정·동일 서비스 주소 제공, 기능 사용 전에는 다운로드하지 않는다. 준비/인식 상태·취소·다시 선택·직접 입력 제공.

## 검색과 상태 분리
기존 TMAP 검색 사용. 유효한 GPS는 주변 검색, 없으면 지역명 입력. 검색어/필요 좌표만 서버로 전달한다. 사진 결과는 주변 장소 확인용이며 GPS Fix·출발지·목적지·진행 중 안내를 덮어쓰지 않는다. 후보 하나도 자동 확정하지 않고 사용자 선택을 받는다. 사진·인식 글자·선택 장소는 저장하지 않는다. 언어 자료 캐시는 사진과 구분한다.

## 자원과 실패 처리
취소/새 사진/뒤로가기/화면 이탈 시 작업 중단, 검색 abort, 이미지/worker 정리 및 늦은 응답 무시. 사진 선택기의 일시적인 화면 숨김은 업로드 선택을 망가뜨리지 않도록 입력 수명과 인식 작업 취소를 구분한다. 실패·빈 글자·다운로드 실패는 재촬영/재시도/직접 입력, 후보 없음은 검색어/지역 수정으로 연결한다. 첫 실행 오프라인은 보장하지 않는다.

## 코드·검증·완료
사진 화면/OCR 작업을 분리하고 역할·처리 흐름·축소 이유·취소/응답 무시·GPS 분리 이유에 한국어 주석을 작성한다. 푸시/뒤로가기/reduced motion, 입력 오류, OCR/검색 실패·취소·늦은 응답, 모바일360/390/430px와 키보드 접근을 검증한다. 실제 OCR과 모의 OCR을 구분하며 삼성 인터넷/Chrome/PWA 실기기·실제 간판 사진 성능은 별도 기록한다. 문제/원인/해결/결과와 포트폴리오를 갱신하고 빌드/검증 후 커밋·푸시, 운영 반영 여부는 따로 보고한다.
