# 휴대폰 GPS·방향 확인 순서

## 1. 정지 상태에서 GPS 수신과 종료 확인

- https://gilbit.vercel.app/?preview=1&mode=simulation 을 휴대폰 Chrome 또는 Safari에서 연다.
- 실제 GPS 추적 시작을 누른 뒤 위치 권한을 허용한다. 자동으로 권한이 요청되는지와 구분한다.
- 수신 상태와 오차/오래된 위치 관련 문구를 확인한다. 기본 경로는 서울시청 예시이므로 현재 장소에서 경로 이탈로 표시될 수 있다.
- GPS 추적 중지 후 수신이 끝나는지 확인한다. 재시작하고 탭을 숨겼다가 돌아오면 자동 재시작하지 않아야 한다.

## 2. 방향 센서의 권한과 입력 확인

- GPS가 유효하게 수신된 상태에서 실제 방향 센서 시작을 누른다. 브라우저에 따라 별도의 권한 창이 없을 수 있다.
- 세로 화면에서 휴대폰을 바닥과 나란하게 들고 상태를 확인한다. 사람의 몸 방향을 읽는 기능은 아니다.
- 오차 값을 제공하지 않는 브라우저에서는 화살표를 표시하지 않는 것이 현재 구현 정책이다. 상대 방향만 제공/오차 확인 불가/경로 이탈 문구를 그대로 기록한다.
- 기본 예시 경로 밖에서는 유효 화살표 확인을 할 수 없다. 먼저 수신·중지·탭 숨김 해제만 확인한다.
- 실제 위치 근처의 테스트가 필요하면 현장 테스트 경로 설정에서 통행 가능한 짧은 보행로를 따라 본인 기기에 좌표를 입력한다. 좌표를 채팅이나 공개 캡처에 공유할 필요는 없다. 이 경로는 직선 도식이며 도로 길찾기를 보장하지 않는다.

## 3. 실제 TMAP 경로의 GPS 확인

- https://gilbit.vercel.app/?mode=live 에서 근처 장소를 검색하고 목적지를 선택한다.
- 현재 위치 확인 → 도보 경로 찾기를 누른다. 출발·도착 위치는 경로 계산을 위해 TMAP 서버로 전달된다.
- 지도 키는 보류 상태이므로 지도 대신 준비 안내가 나올 수 있다. 거리·시간·전체 안내 목록과 길 안내 시작 버튼은 사용 가능하다.
- 길 안내 시작 후 정지 상태의 수신·중지부터 확인한다. 실외 이동은 주변 확인이 가능한 짧고 익숙한 길에서 진행한다.
- 상단 안내 메뉴에서 일시중지·종료하고 자세히 보기에서 전체 경로/GPS 상태를 확인한다. 남은 거리·단계·이탈·복귀·도착은 관찰 결과이며 측정 전 정확도 성과로 쓰지 않는다. 자동 재탐색·실제 경로의 방향 센서/카메라 AR는 아직 연결하지 않았다.

## 보고 양식

기종/OS, 브라우저/버전, 접속 링크, 확인 날짜, 권한 상태, 시작/수신/중지/탭 전환 결과, 표시 문구, 기대와 다른 점을 기록한다. 이동 좌표·집 주소·키가 보이는 화면은 제외한다. 기존 갤럭시 울트라의 카메라 허용·영상 확인 보고와 이번 GPS/방향 확인을 구분한다.

현재 이 문서는 진행 절차이며 실기기 검증 완료 기록이 아니다. 사용자가 확인한 결과를 받은 뒤 별도 검증 문서에 추가한다.
