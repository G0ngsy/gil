# 이용 기록 저장

- 홈은 최근 목적지 1개만 표시한다. 기록 자세히 보기를 누르면 별도 이용 기록 화면에서 최근 검색·전체 목적지와 삭제 기능을 사용한다. 예시 화면은 예시 이용 기록으로 구분한다.
- 검색어는 유효한 실제 검색 응답을 받았을 때, 목적지는 결과에서 선택했을 때 저장한다. 예시 모드에서는 검색 제출과 장소 선택 시 저장한다.
- 최대 10개씩 최신순이며 중복 항목은 위로 이동한다. 목적지는 이름·주소와 중복 구분 ID만 저장한다.
- 검색 항목은 다시 검색한다. 실제 최근 목적지를 누르면 최신 검색 결과로 이동한다. 좌표를 저장하지 않으므로 저장 기록만으로 경로를 요청하지 않는다.
- 삭제 버튼은 해당 항목을 즉시 삭제한다. 전체 삭제는 확인 후 현재 화면의 모드에 속하는 검색·목적지 기록을 모두 지운다. 취소하면 유지한다.
- 이 브라우저의 localStorage에만 저장한다. 로그인·계정 동기화·DB는 없다. 다른 브라우저·다른 도메인·다른 기기와 공유되지 않는다.
- 실제 기록 키: gilbit.history.v1.live, 예시 기록 키: gilbit.history.v1.demo.
- 최근 검색·목적지 목록에는 경로·위치 좌표·카메라 영상을 저장하지 않는다. 검색어 자체에 사용자가 입력한 주소가 포함될 수 있다. 안내 복원용 경로 좌표는 별도 키에 저장하며 아래 항목을 따른다.
- 저장/삭제가 차단되면 화면에 경고한다. 해당 동작은 메모리에서만 적용되며 이전 저장값이 남을 수 있다.
- 브라우저 데이터 삭제·비공개 모드 종료 등에 따라 기록이 없어질 수 있다. 사이트의 다른 기능은 기록 유무와 독립적으로 사용할 수 있다.

현재 위치 주소 조회 결과는 최근 목적지로 자동 저장하지 않으며 주소/주변 검색용 좌표를 별도 조회 이력으로 저장하지 않는다. 다만 안내 복원용 경로에는 출발 위치와 관련된 경로 좌표가 포함될 수 있다. 사용자가 직접 입력한 검색어와 선택한 목적지의 이름·주소 저장 정책은 유지한다.


## 진행 중인 안내 복원 (2026-11-18)

최근 검색 기록과 별도로 실제 안내의 목적지·경로 좌표·저장 시각을 localStorage의 gilbit.guidance.v1.live에 저장한다. 실시간 GPS 관측·진행값·영상·카메라 활성 상태는 저장하지 않는다. 24시간 이내 안내만 이어갈 수 있으며 만료·잘못된 값은 다음 실행 시 삭제한다. 사용자가 이어가기를 누르기 전에는 위치·카메라 권한을 요청하지 않는다. 종료·도착·이전 안내 삭제 시 제거한다. 저장 실패는 안내 기능을 중단하지 않고 사용자에게 알린다. 경로 좌표는 위치 정보이므로 기기 저장 범위를 최근 검색과 구분한다.
