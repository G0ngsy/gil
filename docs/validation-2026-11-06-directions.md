# 전체 도보 안내 검증

- npm run build: 통과
- npm test: 18개 통과
- npm run test:e2e: 12개 통과 (설치된 Chrome 사용)
- 지도 로딩 실패 시에도 전체 안내 목록 열기, 상세 안내 없음, 키보드 Enter로 펼치기 확인.
- 360·390·430px에서 긴 안내 목록의 가로 넘침 없음. 390px 캡처를 육안 확인했으며 세로 내용은 화면 스크롤로 확인한다.
- 장소·경로·지도·위치 응답은 모의 데이터다. 실제 키 인증과 지도 타일은 검증하지 않았다.
- 첫 브라우저 실행은 제한된 환경에서 서버 준비 대기 상태가 되어 종료 후 권한이 있는 실행으로 재검증했다. 재실행 중 잠시 사용 중인 포트 오류가 있었고 이전 실행 종료 후 12개 모두 통과했다.
