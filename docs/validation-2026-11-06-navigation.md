## 실제 개발 서버로 확인한 범위

- 키가 없는 실제 `/api/navigation?action=config` 응답과 준비 화면을 확인했다.
- 키 없이 가상 장소를 실제 검색 결과처럼 보여주지 않는다.
- 디자인 시안으로 돌아갈 수 있다.

## 모의 데이터로 확인한 범위

- 장소 검색 → 선택 → 위치 버튼 → 도보 경로 요청 → 340m·301초 결과 표시 → 경로 확인 종료.
- 검색만으로 위치 권한을 자동 요청하지 않는다.
- 400m 오차·권한 거부 시 도보 경로 요청을 보내지 않는다.
- 지도 스크립트 실패에도 거리·시간을 유지하고 지도 재시도를 제공한다.
- 늦게 도착하는 검색 응답이 지운 검색어의 결과를 복구하지 않는다.
- 실제 모드에는 시안의 '30m 앞 오른쪽'·카메라 안내를 표시하지 않는다.
- 시안 모드의 구름·연꽃·단청 꽃과 기존 화면 전환을 유지한다.
