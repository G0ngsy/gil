최근 GPS·현장 경로 캡처는 실행 기록에 `test-results/tracking-map-*.png`, `test-results/field-route-*.png`로 남아 있으나 임시 산출물이다. 공개용 증거로 영구 보관한 것으로 간주하지 않는다. 다음 해당 기능 검증 시 필요한 장면을 `docs/portfolio/assets/`에 이름·날짜·모드·기기·코드 버전을 붙여 선별 보관하고 이 표에 링크한다. 폴더만 비워 만들거나 오래된 이미지를 새 결과처럼 복사하지 않는다.

## 배포 상태 해석

과거 [배포 문서](../deployment.md)에는 `gilbit.vercel.app`과 CLI 배포, Git 자동 배포 미연결이 기록되어 있다. 이번 작업에서 원격 사이트나 호스팅 설정을 다시 확인하지 않았다. 따라서 최신 GPS/현장 경로가 현재 그 주소에 반영됐다고 주장하지 않는다. 다음 단계는 최신 커밋의 배포 버전 확인 또는 재배포와 휴대폰 HTTPS 검증이다.

## 앞으로 수집할 근거

- 실기기: 모델·OS·브라우저·코드 버전·경로 조건·권한 상태, 기대/실제 동작, 실패와 재검증 결과.
- GPS: 수신 간격과 정확도·이탈/복귀·도착 지연의 관측값. 정확도 수치는 기준점/측정 방법과 함께 기록하고 민감한 실좌표는 공개 자료에서 분리.
- 사용자 검증: 과제·참여 조건·관찰·질문·실패 원인. 실제 측정 전 개선율이나 만족도를 쓰지 않음.
- 최종 소개: 화면 녹화, 핵심 흐름 캡처, 본인/AI/제공 자료의 기여 범위, 자산 출처. 공식 시안 로고는 사용자 제공이며 프로젝트 문양은 문화포털 다운로드 자산으로 표시하지 않음([디자인 기준](../../DESIGN.md)).

## 2026-11-09 개발 도구 설치 근거

[OpenWiki 설치 기록](../issues/2026-11-09-openwiki-install.md)에 설치기·설정 보존 확인과 실행하지 못한 서버 연결 검증을 구분했다. 새 제품 테스트 결과나 완성된 위키 자료로 집계하지 않는다. 실제 기기의 사용자 폴더 설정/백업과 실행 파일은 저장소에 포함하지 않는다.

현재 상태 변경: 같은 날 사용자 요청으로 OpenWiki를 제거했다. 공식 연동 해제·전용 설치 파일 삭제·다른 Codex 설정 보존과 기본 Node 유지까지 확인했다. 위 설치 결과는 과거 기록이며 현재 활성 도구/완성된 위키로 제시하지 않는다. 자세한 범위는 위 설치·제거 기록에 이어 남겼다.

## 2026-11-09 앱의 모의 방향 카드

단위 전체 88개 통과, 방향 카드 7개+추적 19개 브라우저 통과 후 선택 표시/도착 검증을 보완해 방향 카드 7개를 다시 통과했다. TypeScript/Vite 최종 빌드도 통과했다. 800ms 경계·짧은 흔들림·문구 유지·확인 불가 즉시 숨김·꺾임·이탈/복귀·도착/종료·GPS 모드/경로 변경 및 360/390/430px을 검사했다. [상세 결과](../issues/2026-11-09-facing-card.md).

[반대 방향 안내 캡처](assets/2026-11-09-facing-opposite-390.png)는 2026-11-09 로컬 Playwright/Chrome의 390×844 화면이며 실제 센서/실외 결과가 아닌 `mode=simulation` 모의 GPS·방위각 180°/오차 5° 장면이다. 브라우저 시계는 전환 시간을 검사하기 위해 고정했다. 방향 카드 구현을 추가한 같은 커밋의 소스로 생성했으며 해당 커밋은 이 파일의 Git 이력으로 확인한다. 캡처를 직접 열어 문구·화살표·선택 표시를 확인했다. 자료 생성은 사용자 지시에 따른 AI 지원 구현/자동 검증 과정이며 현재 디자인의 사용자 사용성 성과를 증명하지 않는다.

## 2026-11-10 실제 방위 센서 연결 검증

[나침반 단위 테스트](../../tests/compass.test.ts) 12개를 포함해 전체 100개를 통과했다. 공개 WMM 모델 참조점, 보정 부호, 오차/자세/위치/날짜의 거부 조건을 검사했다. [센서 브라우저 테스트](../../tests/browser/heading.spec.ts)는 권한 요청·취소·거부·지연 허용, 센서 수신/중단, 경로/화면/탭/GPS 종료, 시각·화면 회전·오차 미제공을 주입해 검사한다. 최종 범위/결과와 지원 제한은 [상세 이슈](../issues/2026-11-09-heading-sensor.md)에 기록한다. 실제 휴대폰의 방향 정확도나 OS 권한 창을 확인한 결과가 아니다.

진북 보정은 `geomagnetism@0.2.0` 로컬 계산이며 [배포용 라이선스 사본](../../public/licenses/geomagnetism-LICENSE.txt)을 포함한다. 좌표/방위를 외부 서비스에 보내지 않는다. 원래 있던 잠금 파일의 peer 메타데이터 수정은 이번 의존성 추가와 구분해 보존한다.

최종 결과: 센서 14개 재검증 통과, 관련 모의 카드 7개·GPS 19개 통과, 단위 전체 100개와 최종 빌드 통과. [360px 센서 카드 캡처](assets/2026-11-10-heading-injected-360.png)는 2026-11-10 로컬 Chrome/Playwright, 360×844에서 GPS·WebKit 나침반 이벤트를 주입한 화면이다. 진북 보정과 표시는 실행했지만 실기기 나침반 캡처가 아니다. 브라우저 시각은 모델 기간 내 2026-11-09로 고정했고 이 카드 구현과 같은 커밋의 소스로 생성했다. 캡처를 열어 문구·화살표·권한 조작과 미검증 표시를 확인했다.

## 2026-11-10 — 지도 키 공유 안내 정정(현재 정책)
